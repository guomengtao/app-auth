# 用户安装流程分析与优化方案

> **痛点**：大量用户不会给手环/手表安装应用，第一步就卡住。  
> **分析日期**：2026-09-19

---

## 一、当前问题：user-guide.html 的 Step 1 是错误引导

### 1.1 当前 Step 1 的内容

user-guide.html 让用户点击 `bandbbs.cn` 链接去下载：

```
Step 1: 下载并安装手环 App
点击下方链接下载对应你机型的手环 App

10 Pro 方屏 → bandbbs.cn/resources/7778
9 Pro 方屏  → bandbbs.cn/resources/7828
9 Pro 胶囊  → bandbbs.cn/resources/7829
S3/S4 圆屏  → bandbbs.cn/resources/7830
10 Pro 胶囊 → bandbbs.cn/resources/7877
```

### 1.2 为什么这是错的

| 用户看到 | 实际情况 |
|---------|---------|
| 一个网页，有截图、描述、评论区 | **这不是安装界面**，是米坛社区的资源帖子页 |
| 有「下载」按钮 | 点击下载的是 `.rpk` 文件到**手机存储** |
| 以为下载完就装好了 | `.rpk` 文件**无法双击安装**，需要 Astrobox 才能推送到手环 |

**用户体验断裂**：

1. 用户点链接 → 打开米坛社区网页 → 一脸懵
2. 找到下载按钮 → 下载了 .rpk 文件 → 不知道怎么用
3. 尝试打开 .rpk → 系统提示「无法打开此文件」→ 放弃
4. 最终私信作者：『你的软件怎么安装啊？』← **运维成本上升**

## 二、正确安装流程：必须通过 Astrobox

### 2.1 什么是 Astrobox

Astrobox 是小米手环/手表社区的主流应用管理工具：

- **平台**：Android（仅支持安卓手机）
- **功能**：
  - 浏览/搜索社区应用（rpk 格式）
  - 一键下载并推送到手环/手表（通过蓝牙）
  - 管理已安装的应用（更新、卸载）
- **下载方式**：官网 `https://astrobox.online/downloads/` / 酷安 / 米坛社区

### 2.2 正确流程（6 步）

```
Step 0：用户有一台 Android 手机 + 小米手环/手表（蓝牙已配对）

Step 1：手机安装 Astrobox
  → 从酷安或米坛下载 Astrobox.apk 并安装

Step 2：在 Astrobox 内搜索"EV课程表"
  → 打开 Astrobox → 搜索栏输入「EV课程表」→ 搜索

Step 3：点击下载
  → 找到 EV课程表 → 点击「下载」→ Astrobox 自动通过蓝牙推送到手环

Step 4：手环上打开「Ev课程表」
  → 首次打开自动显示「设备ID」

Step 5：打开激活页面（扫码或手动输入）
  → 手环 App 内生成二维码 → 手机扫码 → 跳转 activate.html?deviceId=xxx
  → 或手动输入设备ID访问 activate.html

Step 6：输入兑换码 → 获取激活码 → 输入到手环 → 完成
```

### 2.3 关键理解

| 误解 | 真相 |
|-----|------|
| 从 bandbbs.cn 下载就能装 | bandbbs.cn 只是资源索引站，不负责安装 |
| rpk 文件可以直接装 | rpk 必须通过 Astrobox 或其他工具推送 |
| iPhone 用户也能装 | Astrobox 仅 Android，手环配对也只能用 Android |

## 三、能否跳过「搜索」这一步？（Deep Link 分析）

### 3.1 用户的期望

用户希望点击一个链接，就能直接打开 Astrobox 并到达 EV课程表 的下载页面，**无需手动搜索**。

### 3.2 Android Deep Link 机制

Android 支持三种方式：

#### 方式 A：自定义 URL Scheme（最常用）

```
格式：astrobox://<path>?<params>
```

如果 Astrobox 注册了 `astrobox://` scheme，理论上可以：

```
astrobox://resource/7778        # 直接打开资源 ID 7778
astrobox://search?q=EV课程表     # 直接搜索
astrobox://install?rpk=xxx      # 直接安装
```

**可行性取决于 Astrobox 是否实现了这些 scheme**。

#### 方式 B：App Link（Android 6.0+）

```
格式：https://astrobox.example.com/resource/7778
```

需要 Astrobox 在 AndroidManifest.xml 中注册 intent-filter，且域名归 Astrobox 所有。网站无法模拟。

#### 方式 C：Intent URL（安卓原生）

```
格式：intent://resource?id=7778#Intent;scheme=astrobox;package=com.astrobox.app;end
```

**但这在网页中通常被浏览器安全策略阻止**，不稳定。

### 3.3 实际情况

| 方法 | 可行性 | 原因 |
|------|:------:|------|
| `astrobox://` deep link | ⚠️ 不确定 | 需要验证 Astrobox 是否支持、支持哪些 path |
| `intent://` URL | ❌ 不推荐 | 浏览器安全策略限制，用户大概率看到错误页 |
| bandbbs.cn 直链 | ❌ 误导 | 下载 rpk 文件后用户不会装 |
| 让用户手动搜索 | ✅ 可靠 | 虽然多一步，但 100% 可用 |

### 3.4 建议：给出 Deep Link 备选 + 兜底说明

如果 Astrobox 确实支持 `astrobox://search?q=EV课程表`，那么可以这样设计：

```html
<!-- 优先：一键直达 Astrobox 搜索 -->
<a href="astrobox://search?q=EV%E8%AF%BE%E7%A8%8B" onclick="fallback()">
  一键跳转 Astrobox 下载
</a>

<!-- 兜底：如果手机没装 Astrobox，跳到安装指南 -->
<div id="fallback" style="display:none">
  <p>请先安装 Astrobox：</p>
  <a href="https://www.coolapk.com/apk/...">从酷安下载</a>
  <p>然后搜索「EV课程表」</p>
</div>
```

**但前提是验证 `astrobox://search` 确实可用。** 需要在实际安装了 Astrobox 的 Android 手机上测试。

## 四、改进方案

### 4.1 user-guide.html 重构建议

**将 4 步重新拆为 6 步**，加一个 Step 0 说明前置条件：

```
Step 0：确认环境（前置条件）
  ☐ Android 手机
  ☐ 小米手环/手表已通过小米运动健康 App 与手机配对成功
  ☐ 手机已安装 Astrobox（下面有下载链接）

Step 1：搜索并安装 EV课程表
  ① 打开手机上的 Astrobox
  ② 搜索「EV课程表」
  ③ 点击「下载」，等待推送到手环
  ④ 推送完成后在手环上打开

Step 2：查看设备 ID
  手环上打开 EV课程表 → 首页显示「设备ID: xxxx」

Step 3：购买并获取兑换码
  前往爱发电赞助 → 收到邮件中的 4 位兑换码

Step 4：在线兑换获取 18 位激活码
  手机浏览器打开 activate.html → 输入设备ID + 兑换码 → 获取激活码

Step 5：输入激活码到手环
  手环 App 中进入「激活」入口 → 输入 18 位激活码 → 完成
```

### 4.2 关键改进点

| 原版问题 | 改进后 |
|---------|-------|
| 没有提 Astrobox | Step 1 明确写「打开 Astrobox」 |
| 引导去 bandbbs.cn | bandbbs.cn 链接保留作为备用，但不作为第一步 |
| 没有说明需要 Android 手机 | Step 0 明确写前置条件 |
| 没有 rpk 说明 | 注明「.rpk 需要通过 Astrobox 推送」 |
| 只有 5 个下载按钮 | 改为：先引导安装 Astrobox，再搜索 EV课程表 |

### 4.3 下载链接处理

**保留 bandbbs.cn 链接但降级**：

bandbbs.cn 链接不放 Step 1，而是在 FAQ 中作为「在哪里可以查看版本说明和截图」的引用。在 Step 1 中改为：

```
如果你还没有安装 Astrobox：
  → 从官网下载 Astrobox：https://astrobox.online/downloads/
  → 或从酷安下载：https://www.coolapk.com/apk/...

安装完成后，在 Astrobox 内搜索「EV课程表」并下载。
你的机型对应以下版本：

  10 Pro 方屏 · 9 Pro 方屏 · 9 Pro 胶囊 · S3/S4 圆屏 · 10 Pro 胶囊

（如果搜索不到，请到 bandbbs.cn 手动下载 .rpk 文件，
 然后在 Astrobox 中通过「本地安装」导入）
```
