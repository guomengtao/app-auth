# 后台 UI 升级方案（`admin_Dx23.html`）

> 目标：把后台从「同一套配色在别的系统里好看、在这里难受」的状态，改成**黑白分明、层次清晰、间距统一**的界面。
> 结论先说：**问题不是配色选得不好，而是配色根本没生效** —— 10 套主题里 4 个关键变量完全相同，
> 7 处卡片背景引用了一个不存在的变量，165 个硬编码颜色绕过主题，再加上 24 档字号 / 12 档圆角 / 755 处内联样式。
>
> 本文只做**方案，未改代码**。

---

## 1. 现状体检（全部为实测数据）

| # | 问题 | 实测证据 | 观感后果 |
|---|---|---|---|
| 1 | **10 套主题里 4 个核心变量完全相同** | `--surface` / `--card-bg` / `--ink` / `--line` 在 10 个主题里分别是 `#ffffff` / `#ffffff` / `#0b1120` / `#d1d9e6`，一字不差 | 「换主题」实际只换了页面灰底和主色 → 十套主题看起来几乎一样 → **这就是「配色弄过好几次还是难受」的根因** |
| 2 | **`--card` 变量不存在（CSS 里引用 7 次）** | 定义的是 `--card-bg`，但 7 处写的是 `background:var(--card)` | 这 7 个卡片**没有背景**（透明），和旁边有白底的卡片并列 → 卡片边界时有时无 → 「黑白不分明」 |
| 3 | **165 个不同的硬编码颜色** | `#fff`×48、`#ffffff`×42、`#6b7280`×47、`#dc2626`×39、`#d1d9e6`×37、`#e5e7eb`×33… | 主题切换覆盖不到这些颜色（`background:#e5e7eb` 就有 16 处）→ 改了主题还是「白一块灰一块」 |
| 4 | **结构失控** | 一个 `<style>` 块 84KB / 620 条规则，同时有 **755 处内联 `style="…"`** | 同样的卡片有 5 种写法 → 无法统一，改一处漏十处 |
| 5 | **字号没有级数** | 24 档，其中 `0.65~0.85rem` 之间挤了 14 档（0.65/0.66/0.68/0.7/0.72/0.74/0.75/0.76/0.78/0.8/0.82/0.84/0.85…） | 差异化不可见，只剩「乱」；表格里 12px/12.5px 混用 |
| 6 | **圆角 / 间距没有级数** | 圆角 12 档（2/3/4/5/6/8/10/12/14/999px/50%/var）… padding 14 种（`6px 8px`/`3px 8px`/`1px 6px`/`7px 8px`/`10px 12px`…），gap 9 种（4/6/8/10/12/14/16/20/0） | 边距「差不多的不一样」→ 视觉上永远差一口气 |
| 7 | **对比度不达标（关键）** | 见下表，`#9ca3af` 文字 2.54:1、`#d1d9e6` 描边 1.42:1、卡片 vs 页面底仅 1.23:1 | 文字发虚、边框看不见、卡片浮不起来 → **「黑的黑白的白」做不到** |

### 1.1 对比度实测（WCAG：正文 ≥4.5，大字/边框 ≥3.0）

| 元素 | 比值 | 判定 |
|---|---|---|
| 正文 `#0b1120` on 白 | 18.83 | ✅ |
| 次要文字 `--muted #4b5563` on 白 | 7.56 | ✅ |
| 更浅文字 `#6b7280`（内联用了 47 次） | 4.83 | 🟡 勉强 |
| 更浅文字 `#9ca3af`（22 次） | **2.54** | ❌ 不合格 |
| 更浅文字 `#94a3b8`（16 次） | **2.56** | ❌ 不合格 |
| 链接/主色 `#6366f1` on 白 | 4.47 | 🟡 小字号下勉强 |
| 描边 `--line #d1d9e6` on 白 | **1.42** | ❌ 几乎看不见 |
| 描边 `--line` on 页面底 `#e4e8ef` | **1.16** | ❌ 完全看不见 |
| 卡片 `#ffffff` vs 页面底 `#e4e8ef` | **1.23** | ❌ 卡片浮不起来 |

> 「同一套配色在别的系统好看」的技术差异就在这里：别的系统是
> **页面底(灰) → 卡片(白) → 描边(可辨识) → 阴影(2~3 档)** 四层叠加；
> 这里是 **灰底 → 白卡（有的还是透明卡）→ 几乎不可见的 1px 描边 → 只有 1 档 `0 1px 3px rgba(0,0,0,.06)` 阴影**，
> 层级数不够，于是「白的不亮、黑的不沉」。

## 2. 升级策略（低风险优先）

`admin_Dx23.html` 是 9700 行单文件 + 755 处内联样式，**一次性重写风险极高**。
所以采用**「先修变量与主题 → 再加令牌与组件层 → 最后逐块清内联」**三步走：

```
P0  修 bug + 换数值    → 复用现有变量名（--bg/--surface/--card-bg/--ink/--muted/--line/--accent），
                        不动 84KB CSS 里的选择器，界面立刻变好看
P1  令牌 + 组件覆盖层   → 追加一层 tokens/组件 CSS，把高频内联样式换成类名
P2  真·暗色模式 + 主色化 → 10 套主题降级为「1 亮 + 1 暗 + 10 个主色」
```

**关键点：P0 不改选择器、不改结构，只改变量值和补上未定义变量**，所以 620 条规则会自动跟着变 —— 性价比最高。

## 3. P0：修 bug + 换数值（当天可验证）

### 3.1 修掉 7 处无效变量引用（这是「卡片没有背景」的直接原因）

```css
/* 兼容层：放在 <style> 最前面，把历史写错的变量名兜住 */
:root { --card: var(--card-bg); }   /* 原代码 7 处 var(--card) 立即生效 */
```
> 更稳的做法是同时把这 7 处 `var(--card)` 改成 `var(--card-bg)`（以及 `var(--card-bg,#fff)` 这种带兜底的统一成 `var(--surface)`），
> 但兼容层能让改动范围可控，两者可以一起做。

### 3.2 三层色 + 三档文字（含实测对比度）

```css
[data-theme="light"] {
  /* 层 1 页面底 / 层 2 卡片 / 层 3 浮层 */
  --bg:        #eef1f6;   /* 页底灰（比现在的 #e4e8ef 更中性，不再发蓝） */
  --surface:   #ffffff;   /* 卡片 */
  --card-bg:   #ffffff;
  --elevated:  #ffffff;   /* 弹窗/浮层（配更强阴影） */
  --line:      #d7dde7;   /* 描边：比 #d1d9e6 略深，边界可辨识 */
  --border:    #d7dde7;
  --row-hover: #f6f8fb;
  --th-bg:     #f4f6fa;
  /* 文字三档（不再用 5 档） */
  --ink:       #0f172a;   /* 正文      17.85:1 ✅ */
  --ink-2:     #475569;   /* 次要      7.58:1  ✅ */
  --muted:     #475569;   /* 兼容旧名（原 #4b5563 → 同级） */
  --ink-3:     #64748b;   /* 弱化/时间 4.76:1  ✅（替换 #9ca3af / #94a3b8） */
  /* 主色 */
  --accent:    #4f46e5;   /* 6.29:1 ✅（内联 #6366f1 统一到它，4.47 → 6.29） */
  --accent-2:  #4338ca;
  --sidebar:   #101828;   /* 侧栏保持深色，与内容区形成稳定对比 */
  /* 阴影三档 */
  --shadow-1: 0 1px 2px rgba(15,23,42,.06), 0 1px 3px rgba(15,23,42,.04);  /* 卡片 */
  --shadow-2: 0 2px 6px rgba(15,23,42,.08), 0 4px 12px rgba(15,23,42,.06); /* 悬浮/下拉 */
  --shadow-3: 0 8px 24px rgba(15,23,42,.12);                                /* 弹窗 */
}
```

### 3.3 语义色（统一 `#dc2626/#ef4444/#10b981/#059669/#f59e0b/#8b5cf6` 这些散落的色）

```css
:root {
  --ok:   #059669;  --ok-bg:   #ecfdf5;
  --warn: #b45309;  --warn-bg: #fffbeb;
  --err:  #dc2626;  --err-bg:  #fef2f2;
  --info: #2563eb;  --info-bg: #eff6ff;
}
```
> 现状：成功色同时有 `#10b981`(19) / `#059669`(11) / `#065f46`(10)，失败色有 `#dc2626`(39) / `#ef4444`(21) —— 一律收敛到 4 个语义色。

### 3.4 把 10 套主题改成「真主题 + 主色」

现状 10 个 `data-theme` 只差 `--bg/--accent/--sidebar`，建议：

| 现在 | 改成 |
|---|---|
| deep-blue / jade-green / coral-red / night-black / space-gray / phantom-purple / dawn-white / warm-beige / forest-green / amber-gold | **`color=indigo \| emerald \| rose \| slate \| violet \| blue \| amber`**（只切 `--accent/--accent-2/--sidebar`） |
| — | **`mode=light \| dark`**（切整套三层色 + 文字 + 描边 + 阴影） |

即：**主色 **×** 明暗 = 14 种观感**，而且保证「每套都好看」，因为层级结构是同一套。
`night-black` 现在 `--bg:#e4e5e7`（浅灰）—— 名字叫黑实际是亮色主题，正好说明现状的问题；改完后它应该是 `mode=dark` 的一个主色变体。

## 4. P1：令牌 + 组件覆盖层

### 4.1 字号（24 档 → 7 档）

| 令牌 | 值 | 用途 | 替换掉 |
|---|---|---|---|
| `--fs-11` | 0.6875rem | 徽标/极小注释 | `0.62/0.65/0.66/0.68rem` |
| `--fs-12` | 0.75rem | 表格/次要 | `0.7/0.72/0.74/0.75/0.76rem` |
| `--fs-13` | 0.8125rem | 正文小 | `0.78/0.8rem` |
| `--fs-14` | 0.875rem | 正文 | `0.82/0.84/0.85rem` |
| `--fs-16` | 1rem | 小节标题 | `0.95/1rem` |
| `--fs-20` | 1.25rem | 卡片数字 | `1.05/1.1rem` |
| `--fs-24` | 1.5rem | 统计大数 | `1.5/1.6/2rem` |

### 4.2 间距（8pt 栅格，14 种 padding → 5 档）

```css
--sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-6:24px; --sp-8:32px;
/* 表格单元：padding: var(--sp-2) var(--sp-3)   （统一现在的 6px8px / 7px8px / 8px12px） */
/* 面板：padding: var(--sp-4)（统一 16/20px）；面板间距 gap: var(--sp-4)（统一 14/18px） */
```
圆角只留三档：`--r-sm:6px; --r-md:10px; --r-lg:14px; --r-pill:999px`（替换 12 档）。

### 4.3 统一组件（把「一个东西多种写法」收敛）

| 组件 | 现状 | 目标 |
|---|---|---|
| 卡片 | `background:var(--card)` / `var(--card-bg)` / `var(--surface)` / `#fff` / `#e5e7eb` 五种 | 一类 `.card`：`背景 var(--surface)` + `1px solid var(--line)` + `shadow-1` + `radius var(--r-md)` + `padding var(--sp-4)` |
| 表格 | 三种表头写法、`font-size` 0.7~0.82 混用 | 一类 `.table`：表头 `--fs-12` + `--th-bg` + 下边框 `2px var(--line)`；行 hover `--row-hover`；单元格 `padding var(--sp-2) var(--sp-3)` |
| 按钮 | `.btn` + 满屏内联 padding/font-size | `.btn`/`.btn-sm`/`.btn-primary`/`.btn-outline`/`.btn-danger` 四类，尺寸只两档（28px / 32px 高） |
| 状态徽标 | 每处自己拼颜色 | `.badge.ok/.warn/.err/.info`（用语义色 + `-bg`） |
| 输入框 | `border-color:#cbd5e1` 硬编码 | `1px solid var(--line)`，focus 用 `--accent` + `0 0 0 3px rgba(79,70,229,.15)` |

### 4.4 清内联样式（分批，按「出现次数」下手）

```
第 1 批（约 200 处）：表格 cell 的 padding/border/font-size  → 交给 .table 统管
第 2 批（约 150 处）：卡片容器 background/border/radius      → 交给 .card
第 3 批（约 200 处）：按钮 padding/font-size/color           → 交给 .btn*
第 4 批（约 200 处）：行内文字色 #9ca3af/#94a3b8/#6b7280    → 换 --ink-3 / --muted
剩余：页面独有的布局（flex/grid 宽度）保留内联，属正常用法
```

## 5. P2：暗色模式（必须先做 P1）

⚠️ **顺序不能颠倒**：现在有 47 处 `#6b7280`、22 处 `#9ca3af`、48 处 `#fff`、`#111827`/`#1e293b` 这些**硬编码深浅色**，
直接开暗色模式会出现「深色底 + 深色字」或「深色底 + 纯白卡片」的情况，比现在更灾难。
所以暗色模式放在**硬编码颜色清理完成之后**。

```css
[data-mode="dark"] {
  --bg: #12171f;  --surface: #1b2230;  --card-bg: #1b2230;  --elevated: #202836;
  --line: #2b3542; --border: #2b3542; --row-hover: #202836; --th-bg: #1f2733;
  --ink: #e6ebf3;   /* 13.31:1 ✅ */
  --ink-2: #b6c2d2; --muted: #b6c2d2; --ink-3: #98a6ba;   /* 6.45:1 ✅ */
  --shadow-1: 0 1px 2px rgba(0,0,0,.4);
  --shadow-2: 0 2px 8px rgba(0,0,0,.5);
  --shadow-3: 0 12px 32px rgba(0,0,0,.6);
}
```
暗色下 `--accent` 保持同一主色（同色系的主色在暗底上通常自动达标，`#4f46e5` 在 `#1b2230` 上约 3.4:1，用于文字时改用亮一档 `#8b93ff`）。

## 7. 风险与注意

| 风险 | 说明 | 对策 |
|---|---|---|
| 内联样式优先级 | 内联 `style` 会盖掉类样式，加了 `.card` 也可能不生效 | 覆盖层里对高频项用 `!important` 过渡，清完内联后去掉 |
| 硬编码颜色清理遗漏 | 165 个颜色里有些是图表/状态专用（如 canvas 画图色） | 先按「背景/文字/描边」分类清理，canvas 里的颜色统一从 CSS 变量读（`getComputedStyle`） |
| 主题持久化 | `setTheme()` 写 localStorage，改成「主色 + 明暗」两维后要兼容旧值 | 旧主题名映射到新组合（如 `night-black` → `mode=dark, color=slate`），不丢用户设置 |
| 表格斑马纹 | `table tbody tr:nth-child(even) td { background:#fafbfc }` 硬编码浅灰 | 换成 `var(--row-hover)`，暗色下自动适配 |
| 打印/导出 | 打印样式依赖白底 | `@media print` 里强制亮色变量 |
| 一次性改动过大 | 9700 行单文件，容易改崩 | 分阶段提交，每阶段线上自查截图对比；P0 只动变量，随时可回滚 |

## 附：为什么「同样的配色在别的系统好看」

| 维度 | 别的系统 | 本后台现状 |
|---|---|---|
| 层级 | 页底 / 卡片 / 浮层 三层，各有明度差 | 灰底 + 白卡两层，且有 7 处卡片**透明** |
| 边界 | 1px 描边 + 软阴影同时上 | 描边 1.42:1（看不见）+ 只有 1 档极淡阴影 |
| 文字 | 3 档（主/次/弱） | 5 档，其中 2 档对比度不合格 |
| 字号 | 4~5 档 | 24 档（0.65~0.85 之间 14 档） |
| 间距 | 4/8/12/16/24 栅格 | 14 种 padding、9 种 gap |
| 圆角 | 2~3 档 | 12 档 |
| 颜色总量 | 一个色板 20~30 色 | **165 个硬编码色** |
| 主题 | 一套结构 + 多主色 | 10 套主题，4 个核心变量完全相同 |

**一句话**：不是配色不行，是**层级、对比度、级数、变量**这四件事没做，配色换一百次也只是换灰底的色相。
P0 做完（只改变量值），观感会有肉眼可见的改善。
