## CSS 变量模板

以下为通用 CSS 变量结构，替换各方案色值即可快速切换主题：

```css
:root {
  --bg:       #F7F4F0;   /* 背景 */
  --card-bg:  #FFFFFF;   /* 卡片 */
  --ink:      #2C2A28;   /* 主文本 */
  --muted:    #7A7570;   /* 次要文本 */
  --border:   #E6E1DB;   /* 边框 */
  --accent:   #D48C6B;   /* 主色 */
  --accent-2: #B8724F;   /* 强调色 */
}
```

## 当前项目方案

当前 `admin_Dx23.html` 使用 **方案 2：极光靛蓝**，配备 `color-scheme: light dark` 支持自动跟随系统暗色模式。
