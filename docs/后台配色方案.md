# 后台管理系统配色方案（10 套）

以下 10 套配色方案专为后台管理系统设计，基于 `admin_Dx23.html` 的 CSS 变量体系，覆盖背景、卡片、文字、边框、强调色等核心设计角色。

## CSS 变量体系

当前 `admin_Dx23.html` 使用以下 CSS 变量结构，通过 `data-theme` 属性切换主题：

```css
[data-theme="deep-blue"] {
  --bg:              #1a1a2e;   /* 页面背景 */
  --surface:         #16213e;   /* 表面背景 */
  --card-bg:         #16213e;   /* 卡片背景 */
  --ink:             #ffffff;   /* 主文字 */
  --muted:           #888899;   /* 次要文字 */
  --line:            #2a2a5a;   /* 分割线 */
  --border:          #0f3460;   /* 边框 */
  --accent:          #7ec8e3;   /* 强调色（主） */
  --accent-2:        #5ca8c8;   /* 强调色（辅） */
  --sidebar:         #0f0f20;   /* 侧边栏 */
  --sidebar-w:       220px;     /* 侧边栏宽度 */
  --sidebar-w-collapsed: 64px;  /* 收起宽度 */
  --topbar-h:        56px;      /* 顶栏高度 */
  --radius:          10px;      /* 圆角 */
  --th-bg:           #1f1f3a;   /* 表头背景 */
  --row-hover:       #1f1f3a;   /* 行悬停 */
  --about-bg:        #0f3460;   /* 关于区域背景 */
  --about-border:    #2a2a5a;   /* 关于区域边框 */
  --dash-bg:         #16213e;   /* 仪表盘背景 */
  --dash-border:     #0f3460;   /* 仪表盘边框 */
  --status-bar-bg:   linear-gradient(...); /* 状态栏背景 */
  --status-bar-border: #0f3460; /* 状态栏边框 */
}
```

## 当前项目方案

当前 `admin_Dx23.html` 默认使用 **方案 1：深空蓝**，用户可在设置面板中切换任意主题，切换后自动保存到 `localStorage`。
