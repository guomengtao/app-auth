# 后台管理系统 10 种配色方案

本文档整理了 10 种实用的后台管理界面配色方案，涵盖护眼模式、黑夜模式、白天模式等常用功能性风格，以及多种现代设计风格。

---

| 主背景 | `#f8fafc` | 浅灰白，柔和护眼 |

| 文字主色 | `#1e293b` | 深灰蓝，高可读性 |
| 文字辅色 | `#64748b` | 中灰，次要信息 |
| 边框线 | `#e2e8f0` | 浅灰，分割柔和 |

## 实现建议

### 1. CSS 变量切换

将所有颜色定义为 CSS 自定义属性，通过切换 `[data-theme]` 属性实现主题切换：

```html
<html data-theme="light">
```

```css
[data-theme="light"] { /* 方案一 */ }
[data-theme="sepia"] { /* 方案二 */ }
[data-theme="dark"] { /* 方案三 */ }
[data-theme="soft-dark"] { /* 方案四 */ }
[data-theme="high-contrast"] { /* 方案五 */ }
[data-theme="ocean"] { /* 方案六 */ }
[data-theme="forest"] { /* 方案七 */ }
[data-theme="business"] { /* 方案八 */ }
[data-theme="sunset"] { /* 方案九 */ }
[data-theme="cyberpunk"] { /* 方案十 */ }
```

### 2. 主题持久化

将用户选择的主题存入 `localStorage`，页面加载时自动恢复：

```javascript
function setTheme(name) {
  document.documentElement.setAttribute('data-theme', name);
  localStorage.setItem('admin-theme', name);
}

function loadTheme() {
  var saved = localStorage.getItem('admin-theme') || 'light';
  setTheme(saved);
}
```

### 3. 自动切换（跟随系统）

监听系统配色偏好，自动切换亮/暗模式：

```javascript
var darkQuery = window.matchMedia('(prefers-color-scheme: dark)');
darkQuery.addEventListener('change', function(e) {
  if (!localStorage.getItem('admin-theme')) {
    setTheme(e.matches ? 'dark' : 'light');
  }
});
```

### 4. 过渡动画

添加平滑过渡效果，避免切换时闪烁：

```css
body, .sidebar, .panel, .card, button, input, select, textarea {
  transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease;
}
```

## 注意事项

1. **护眼模式**不改变图像和品牌 Logo 的颜色
2. **高对比度模式**需要同时增大字体、加粗边框
3. **黑夜模式**的阴影效果应减弱或取消
4. 所有方案的**成功/警告/错误色**需保持语义清晰（红=错误，绿=成功，不颠倒）
5. 代码编辑器（如 `<pre>`、`<code>`）应保持独立配色，不受主题影响
6. 图表和可视化组件需要单独适配暗色主题
