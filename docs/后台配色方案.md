## 设计原则

**品牌色保留，背景/卡片/文字全部改成"后台专用中性色"**：

- 背景 `--bg`：统一浅色系（`#f1f4f9` ~ `#f5f0e8`），告别深色花哨背景
- 卡片 `--surface` / `--card-bg`：统一纯白 `#ffffff`，干净清爽
- 主文字 `--ink`：统一深灰 `#111827`，高对比度可读
- 次要文字 `--muted`：统一中性灰 `#6b7280`
- 边框 `--line` / `--border`：统一极浅灰 `#e5e7eb`
- 品牌色 `--accent` / `--accent-2`：每套方案独立保留，色调方向不变但色值更稳重专业
- 侧边栏 `--sidebar`：保持深色，与浅色内容区形成对比

## CSS 变量体系

```css
[data-theme="deep-blue"] {
  --bg:              #f1f4f9;   /* 页面背景 */
  --surface:         #ffffff;   /* 表面背景 */
  --card-bg:         #ffffff;   /* 卡片背景 */
  --ink:             #111827;   /* 主文字 */
  --muted:           #6b7280;   /* 次要文字 */
  --line:            #e5e7eb;   /* 分割线 */
  --border:          #e5e7eb;   /* 边框 */
  --accent:          #4F46E5;   /* 品牌色（主） */
  --accent-2:        #4338CA;   /* 品牌色（辅） */
  --sidebar:         #0f172a;   /* 侧边栏 */
  --th-bg:           #f8f9fa;   /* 表头背景 */
  --row-hover:       #fafbfc;   /* 行悬停 */
  --about-bg:        #f8f9fa;   /* 关于区域 */
  --about-border:    #e5e7eb;   /* 关于区域边框 */
  --dash-bg:         #ffffff;   /* 仪表盘背景 */
  --dash-border:     #e5e7eb;   /* 仪表盘边框 */
  --status-bar-bg:   #ffffff;   /* 状态栏背景 */
  --status-bar-border: #e5e7eb; /* 状态栏边框 */
}
```
