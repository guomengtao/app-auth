# 爱发电订单对接功能规划

## 概述

将爱发电（Afdian）赞助订单系统与 app-auth 激活码系统对接，实现：用户赞助后自动生成激活码、通过私信发送激活码给用户。

---

## 核心数据

| 项目 | 值 |
|:---|:---|
| user_id | `1cd05722a1af11f1939c5254001e7c00` |
| Webhook URL | 待配置（`https://app-auth.gudq.com/api/afdian/webhook`） |
| API Token | 已生成（服务端保存，切勿泄露） |
| 公钥 | RSA 公钥（用于 Webhook 签名验证） |

---

## 对接方式

爱发电提供两种方式，建议**两者结合使用**：

| 方式 | 方向 | 用途 | 可靠性 |
|:---|:---|:---|:---|
| Webhook | 爱发电 → 我们 | 实时接收订单通知 | 可能延迟/丢失 |
| API 主动查询 | 我们 → 爱发电 | 定时拉取订单、补漏 | 可靠 |

> 爱发电官方建议：Webhook 可能因服务器异常不保证及时推送，建议结合 API 一起使用。

## 功能模块设计

### 模块一：Webhook 接收（被动通知）

#### 流程

```
用户赞助 → 爱发电 → POST webhook URL → 验证签名 → 处理订单 → 返回 {"ec":200}
```

#### 接口设计

**端点**: `POST /api/afdian/webhook`

**请求体**（爱发电发送）:
```json
{
  "ec": 200,
  "em": "ok",
  "data": {
    "type": "order",
    "order": {
      "out_trade_no": "202106232138371083454010626",
      "custom_order_id": "Steam12345",
      "user_id": "adf397fe8374811eaacee52540025c377",
      "plan_id": "a45353328af911eb973052540025c377",
      "month": 1,
      "total_amount": "5.00",
      "show_amount": "5.00",
      "status": 2,
      "remark": "",
      "redeem_id": "",
      "product_type": 0,
      "discount": "0.00",
      "sku_detail": [],
      "address_person": "",
      "address_phone": "",
      "address_address": ""
    },
    "sign": "xxxxxxxx"
  }
}
```

**响应**:
```json
{"ec": 200, "em": ""}
```

#### 处理逻辑

1. 验证签名（RSA SHA256）
2. 检查 `status === 2`（交易成功）
3. 提取 `out_trade_no`、`user_id`、`plan_id`、`month`、`remark`
4. 根据 `plan_id` 映射到 app-auth 产品
5. 生成激活码
6. 存储订单记录到 Redis
7. 返回 `{"ec": 200}`

#### 幂等处理

- 以 `out_trade_no` 为唯一键，已处理过的订单直接返回成功
- 防止爱发电重复推送

#### 签名验证

```
sign_str = out_trade_no + user_id + plan_id + total_amount
openssl_verify(sign_str, base64_decode(sign), public_key, 'SHA256')
```

### 模块二：API 主动查询（主动拉取）

#### 查询订单

**端点**: `https://ifdian.net/api/open/query-order`

**签名规则**:
```
sign = md5(token + "params" + json_params + "ts" + timestamp + "user_id" + user_id)
```

**请求体**:
```json
{
  "user_id": "1cd05722a1af11f1939c5254001e7c00",
  "params": "{\"page\":1}",
  "ts": 1624339905,
  "sign": "calculated_md5"
}
```

#### 定时任务

- 每 5 分钟执行一次
- 查询最近订单（page=1），对比本地已处理订单
- 未处理的订单补发激活码
- 记录上次查询的 `out_trade_no` 作为游标

#### 查询赞助者

**端点**: `https://ifdian.net/api/open/query-sponsor`

用途：验证用户赞助状态、查看赞助历史。

### 模块三：产品映射

#### 爱发电方案 → app-auth 产品

| 爱发电 plan_id | 方案名称 | 月数 | app-auth 产品 ID | 激活时长 |
|:---|:---|:---|:---|:---|
| 待配置 | 方案A | 1 | 待配置 | 1 个月 |
| 待配置 | 方案B | 3 | 待配置 | 3 个月 |
| 待配置 | 方案C | 6 | 待配置 | 6 个月 |
| 待配置 | 方案D | 12 | 待配置 | 12 个月 |
| 待配置 | 永久方案 | 0 | 待配置 | 永久 |

> 在爱发电创建方案后，在后台配置映射关系。

#### 售卖商品（product_type=1）处理

- 如果 `product_type === 1`，从 `sku_detail` 提取 SKU ID
- 根据 SKU 映射到对应产品

### 模块四：自动回复/私信发码

#### 方式一：API 更新自动回复

**端点**: `/api/open/update-plan-reply`

用户赞助后，通过 API 更新方案的自动回复内容，填入激活码。

```
参数:
  plan_id: 方案 ID
  auto_random_reply: 激活码内容
  update_random_reply_type: "append" 追加
```

#### 方式二：API 发送私信

**端点**: `/api/open/send-msg`

直接给用户发送私信，包含激活码。

```
参数:
  recipient: 赞助者 user_id
  content: "感谢赞助！您的激活码：XXXX"
```

频率限制：10次/秒，1000次/小时。

> 推荐使用方式二（私信），更直接可靠。

|:---|:---|:---|
| `afdian:orders` | Hash | 订单记录，key=out_trade_no |

## 安全注意事项

- API Token 仅存储在服务端环境变量中，绝不出现在前端代码
- Webhook 必须验证 RSA 签名，防止伪造请求
- 私信发码频率控制在限制内（10次/秒，1000次/小时）
- 订单幂等处理，防止重复生成激活码
- 公钥硬编码在服务端代码中（非敏感信息）
