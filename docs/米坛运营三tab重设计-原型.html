设计标注（点工具条「标注」开关）

  1. 页头统一：标题 + 语义副标题（含「上次抓取」相对时间）+ 全局动作（刷新 / 手动抓取）。抓取状态从"无归属"收进顶栏徽章。
  2. 三 Tab 签条：直接复用设置页 .settings-tabs 规格（44px 高、4px 内衬、选中填充主色）。新增右上角计数徽章，把"有多少条待处理"提到第一眼。
  3. KPI 行：把原 4 张卡重排为「规模 → 产出 → 结果(主色高亮) → 时效」，主色高亮落在真正需要盯的「已发放奖励」。
  4. 资源帖配置：主操作区。表格新增「新增评论」，失败/限流状态直接染色，一眼看出哪个资源卡住了。
  5. 最近抓取结果：由裸 JSON 改为「状态点 + 资源 + 结果徽章」三栏对齐，失败原因文本化（HTTP 502 / 限流）。
  6. 测试工具折叠：测试私信属低频调试能力，收进 <details>，不再占用主视线。
  7. 详情页筛选栏：原 2 个下拉扩为「资源 / 奖励状态 / 星级 / 关键词」四维，并加「重置」，避免筛到一半退不回去。
  8. 奖品库存总览：库存/已发/剩余三卡，剩余量给主色高亮 + 速率预估，回答"还够发几天"。
  9. 模板区降噪：奖励产品、私信模板各自独立成卡，长文本域宽度拉满，不再挤在一列英文标签里。
  10. 批量导入：等宽字体 + 行提示 placeholder + "最近一次导入"回执，导入类操作必须给后置反馈。
