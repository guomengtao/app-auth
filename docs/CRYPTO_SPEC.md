# 加密需求与技术分析

## 需求

| 项目 | 要求 |
|------|------|
| 输入 | 12位字符，4组 |
| 第1组 | 2位纯数字 (0-9) | 产品id
| 第2组 | 4位大写字母+数字 (A-Z 0-9) | 校验码
| 第3组 | 2位纯数字 (0-9) | 代表激活的月份数 
| 第4组 | 4位大小写字母+数字 (A-Z a-z 0-9) | 设备id
| 输出 | 18位纯数字 |
| 可解密 | 必须还原原始14位字符 |

示例：`98ASDF39aA4D`

服务器和手环只保存一个全局主盐（比如 k3f9x）
产品盐 = HMAC(全局主盐, 产品ID) 的前5位

js命令行实现要求 , 格式 node test/crypto.js 98ASDF39aA4D
返回格式:
加密结果:输入出18位纯数字
解密结果:输入出14位字符
对比一致 ✅
