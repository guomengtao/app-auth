# 版本号自动更新方案

## 一、现状分析

### 1.1 当前版本号位置

| 位置 | 内容 | 问题 |
|------|------|------|
| `package.json` | `"version": "1.0.0"` | 从未更新，与实际进度不符 |
| `admin_Dx23.html` 侧边栏 | `<span class="sidebar-ver">v1.0</span>` | 硬编码，手动改 |
| Git tag | 无 | 从未打过 tag |

### 1.2 版本号格式

采用 `主版本.次版本.修订版本` 语义化版本：

```
v1.1.3
  │ │ └── 修订版本（patch）每次 push 自动 +1
  │ └──── 次版本（minor）功能新增时手动 +1
  └────── 主版本（major）重大重构时手动 +1
```

当前版本：`1.1.2`（基于已有提交推算）

## 二、方案设计

### 2.1 版本号唯一来源

创建 `version.json` 作为版本号的唯一真相来源：

```json
{
  "version": "1.1.2"
}
```

所有其他地方（后台页面、脚本等）都从这里读取，确保一致。

### 2.2 自动递增规则

每次 push 时，只自动递增 `patch` 位（第三位）。

| 场景 | 操作 | 示例 |
|------|------|------|
| 普通 push | patch +1 | 1.1.2 → 1.1.3 |
| 功能发布 | 手动改 minor，patch 归零 | 1.1.3 → 1.2.0 |
| 重大重构 | 手动改 major，其余归零 | 1.2.0 → 2.0.0 |

### 2.3 后台显示

在 `admin_Dx23.html` 侧边栏底部显示版本号，已有占位：

```html
<span class="sidebar-ver">v1.1.3</span>
```

改为动态读取 `version.json`：

```javascript
fetch('/version.json')
  .then(function(r) { return r.json(); })
  .then(function(data) {
    document.querySelector('.sidebar-ver').textContent = 'v' + data.version;
  });
```

## 三、文件结构

```
app-auth/
├── version.json              # 版本号唯一来源
├── scripts/
│   ├── bump-version.sh       # 递增 patch 版本号
│   └── push.sh               # 一键 push：bump + commit + push
├── admin_Dx23.html           # 后台页面，动态读取 version.json 显示
└── package.json              # 可选：从 version.json 同步
```

## 四、脚本实现

### 4.1 `scripts/bump-version.sh` — 版本号递增

```bash
#!/bin/bash
# 读取 version.json，patch 位 +1，写回

VERSION_FILE="version.json"
CURRENT=$(node -e "console.log(require('./version.json').version)")
MAJOR=$(echo $CURRENT | cut -d. -f1)
MINOR=$(echo $CURRENT | cut -d. -f2)
PATCH=$(echo $CURRENT | cut -d. -f3)
NEW_PATCH=$((PATCH + 1))
NEW_VERSION="${MAJOR}.${MINOR}.${NEW_PATCH}"

echo "{\"version\": \"$NEW_VERSION\"}" > "$VERSION_FILE"
echo "版本: $CURRENT → $NEW_VERSION"
```

### 4.2 `scripts/push.sh` — 一键 push（推荐）

```bash
#!/bin/bash
# 用法: ./scripts/push.sh "提交信息"
# 自动 bump 版本号 → git add → git commit → git push

set -e

if [ -z "$1" ]; then
  echo "错误: 请提供提交信息"
  echo "用法: ./scripts/push.sh \"修复了某某问题\""
  exit 1
fi

# 1. 递增版本号
./scripts/bump-version.sh

# 2. 读取新版本号
NEW_VERSION=$(node -e "console.log(require('./version.json').version)")

# 3. Git 操作
git add -A
git commit -m "$1 (v$NEW_VERSION)"
git push

echo ""
echo "✅ 推送完成! 版本: v$NEW_VERSION"
```

### 4.3 也可以拆开使用

```bash
# 方式一：一键 push（推荐）
./scripts/push.sh "修复激活页面样式问题"

# 方式二：手动分步
./scripts/bump-version.sh     # 先 bump 版本
git add -A
git commit -m "消息内容"
git push
```

## 五、后台显示实现

### 5.1 修改 `admin_Dx23.html`

在页面初始化时 fetch `version.json`：

```javascript
function loadVersion() {
  fetch('/version.json')
    .then(function(r) { return r.json(); })
    .then(function(data) {
      var el = document.querySelector('.sidebar-ver');
      if (el) el.textContent = 'v' + data.version;
    })
    .catch(function() {
      // 离线或文件不存在时保持硬编码兜底
    });
}

// 在 initLocalData() 或 DOMContentLoaded 中调用
loadVersion();
```

### 5.2 侧边栏 HTML 保留兜底

```html
<span class="sidebar-ver">v1.1.2</span>
<!-- 页面加载后 JS 会替换为真实版本号 -->
```

## 六、完整流程示例

```
当前版本: 1.1.2

$ ./scripts/push.sh "安全加固：文件重命名防猜测"
  1. bump-version.sh 执行
  2. version.json: 1.1.2 → 1.1.3
  3. git add -A
  4. git commit -m "安全加固：文件重命名防猜测 (v1.1.3)"
  5. git push 成功
  6. 后台侧边栏显示 v1.1.3

下次 push:
$ ./scripts/push.sh "新增功能"
  → 1.1.3 → 1.1.4
```

## 七、版本号不自动递增的场景

以下情况需要手动修改 `version.json`：

| 场景 | 手动操作 |
|------|---------|
| 发布新功能（minor） | 改 `version.json` 为 `1.2.0` |
| 重大重构（major） | 改 `version.json` 为 `2.0.0` |
| 不想改变版本号 | 用普通 `git push`，不用 `scripts/push.sh` |

## 八、可选扩展

### 8.1 Git Tag

在 push.sh 中加一行自动打 tag：

```bash
git tag "v$NEW_VERSION"
git push --tags
```

### 8.2 同步 package.json

在 bump-version.sh 中同时更新 package.json：

```bash
node -e "
  var pkg = require('./package.json');
  pkg.version = '$NEW_VERSION';
  require('fs').writeFileSync('./package.json', JSON.stringify(pkg, null, 2) + '\n');
"
```

### 8.3 Build Number

如果希望更精细，可加 build 号：

```json
{
  "version": "1.1.2",
  "build": 42
}
```

每次 push 时 build 号 +1，版本号不变。适合频繁 push 但不想版本号变得太大的场景。

## 九、总结

| 要点 | 说明 |
|------|------|
| 版本源 | `version.json` 唯一真相来源 |
| 递增规则 | 每次 push 自动 patch +1 |
| 显示位置 | 后台侧边栏底部，动态读取 |
| 操作方式 | `./scripts/push.sh "提交信息"` 一键完成 |
| 灵活性 | 手动改 version.json 可控制 major/minor |
