# 兑换码管理页面打不开 - 问题分析与修复文档

## 问题描述

后台管理系统中，点击左侧菜单「兑换码管理」后，页面内容区域无法正常显示兑换码列表，表现为空白或加载失败。

## 问题诊断时间

2026-08-31

## 根因分析

### 问题 1：核心架构违规 - 兑换码页面使用在线数据库（严重）

**严重程度：致命**

根据项目规则：
> Only one of Products detail page could like online db, other all use local json file get data and build the static html files.
> （只有产品详情页可以使用在线数据库，其他所有页面必须使用本地 JSON 文件获取数据并构建静态 HTML 页面。）

**当前实现问题：**

`admin.html` 中的 `loadCodes()` 函数（第 704-738 行）调用在线 API：
```javascript
var data = await api('/api/admin/redeem-codes?' + params.toString());
```

该 API (`/api/admin/redeem-codes.js`) 依赖 Redis 数据库：
```javascript
var redis = require("../../lib/redis");
// ...
var memberResult = await redis.sscan("auth:redeem_codes", memberCursor, { count: 200 });
```

**故障链：**
1. 本地开发环境未配置 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN` 环境变量
2. Redis 客户端初始化失败或连接超时
3. `/api/admin/redeem-codes` 返回 500 Internal Server Error
4. `loadCodes()` 中虽然有 catch 块，但 API 返回 500 时 `res.json()` 可能解析出错误格式
5. 用户看到空白表格区域，无有效数据展示

### 问题 2：导出功能同样依赖在线 API

`exportCodes()` 函数（第 740-782 行）同样调用 `/api/admin/redeem-codes?export=1`，存在相同的 Redis 依赖问题。

### 问题 3：生成兑换码功能依赖在线 API

`generateCodes()` 函数（第 862-887 行）通过 POST 调用在线 API 创建兑换码，同样依赖 Redis。

### 问题 4：激活记录面板存在相同问题

`loadRecords()` 函数调用 `/api/admin/records` API，同样使用 Redis 数据库，违反项目规则。

### 问题 5：统计面板数据依赖在线 API

`loadStats()` 函数调用 `/api/admin/stats` API，依赖 Redis 数据库。

## 影响范围

| 模块 | 依赖在线API | 状态 | 修复优先级 |
|------|-------------|------|------------|
| 兑换码管理列表 | ✅ 是 | ❌ 违规 | P0 紧急 |
| 兑换码导出CSV | ✅ 是 | ❌ 违规 | P0 紧急 |

| 解密验证 | ✅ 是 | ✅ 算法本地可计算 | 待评估 |

## 修复方案

### 方案概述

将兑换码管理、激活记录、统计面板改为使用本地 localStorage + JSON 文件存储数据。产品管理保留在线 API（符合规则）。

### 数据结构设计

#### 1. 兑换码数据结构 (redeemCodes)

```json
[
  {
    "code": "AB12",
    "product_id": "01",
    "duration_months": 12,
    "used": false,
    "used_device_id": null,
    "generated_activation_code": null,
    "created_at": 1756646400000,
    "used_at": null
  }
]
```

#### 2. 激活记录数据结构 (activationRecords)

```json
[
  {
    "activation_code": "010001120000000001",
    "device_id_hash": "a1b2c3d4",
    "product_id": "01",
    "duration_months": 12,
    "generated_at": 1756646400000,
    "expires_at": 1788182400000,
    "redeem_code": "AB12"
  }
]
```

### 实现步骤

#### 步骤 1：创建本地数据初始 JSON 文件

创建 `/data/redeem-codes.json` 存储示例兑换码数据。

#### 步骤 2：创建 `/data/activation-records.json` 存储示例激活记录。

#### 步骤 3：修改 `admin.html` 中的数据加载逻辑

- `loadCodes()`：从 localStorage 读取，首次加载从 JSON 文件初始化
- `loadRecords()`：从 localStorage 读取，首次加载从 JSON 文件初始化
- `loadStats()`：基于本地数据计算统计值
- `generateCodes()`：本地生成兑换码并存入 localStorage
- `exportCodes()`：从 localStorage 读取数据导出 CSV

#### 步骤 4：添加本地数据持久化工具函数

```javascript
function getLocalData(key, fallback) {
  try {
    var raw = localStorage.getItem(key);
    if (raw) return JSON.parse(raw);
  } catch (e) {}
  return fallback;
}

function saveLocalData(key, data) {
  localStorage.setItem(key, JSON.stringify(data));
}
```

#### 步骤 5：保留产品管理使用在线 API

产品管理模块（loadProducts, addProduct）继续调用在线 API，符合项目规则。
