## 一、本轮结论摘要

> **一句话**：本轮把「数据库主库协调器」从 Upstash 换成了 Vercel Edge Config —— 这是一个**高风险改动，且改得不完整**：后台切换主库现在会**无条件返回"切换成功"但实际可能什么都没存下来**，存在激活数据 split-brain 风险；同时上轮的头号 P0（激活页按钮卡死）**一轮未修，线上仍在发生**。

**关键风险（只谈能否用起来）**

| 级别 | 一句话 |
|------|--------|
| 🔴 P0 | **P0-16 未修**：激活页点一次「立即激活」后按钮**永久卡在「激活中…」且不可再点**。首次输错兑换码的用户**无法重试，只能刷新页面**。线上已确认存在。 |
| 🔴 P0 | **P0-17 新增**：后台「切换主库」永远返回 success，但写入 Edge Config 失败时**静默吞掉**（无 throw、无日志、无告警）→ 主库可能只在单个 Lambda 内存里变了 → **不同实例读写不同库，用户已激活却显示未激活**。 |
| 🔴 P0 | **P0-15 仍未确认**：`CRON_SECRET` 是否配置未知。未配置则每日 04:00 备份 / 05:00 同步**永久 401**，且后台「立即执行」也 401。 |
| 🟡 P1 | 上轮 5 条 P1（CSS 逗号被吞 / 手册下载链接 / 手册与代码冲突 / 两页残留 ES6 / 复制按钮无降级）**全部未修**。 |

**本轮没有新增 P1 及以上缺陷，唯一的新 P0 来自 db-switches 重构。**

## 五、数据源一致性

| 数据源 | 角色 | 本轮影响 |

**风险判定（只在会导致用户状态错乱时才算 P0）**

- **P0-17 是本轮唯一会造成用户状态错乱的项**：`savePrimary` 不可靠 → 主库在不同 Lambda 实例间不一致 → 激活写 A 库、校验读 B 库 → 用户已付款却显示未激活。
- `lib/redis.js` 在模块加载期用 `process.env.DB_PROVIDER` 锁定 Upstash/Postgres，而 `lib/postgres.js` 在每次 query 前用 Edge Config 的 `cachedPrimary` 路由 —— **两层口径不一致**（P3-15）。目前未观察到实际错乱，但一旦管理员切换主库，行为难以预测。
- 备份/同步脚本：本轮未改动；`scripts/clear-db.js:12`、`scripts/force-sync.js:37` 的 `--confirm` 护栏**仍在**，无覆盖写风险。

## 八、回归测试建议（给开发的可执行 checklist）

**A. 激活主链路（20 分钟，必做）**
1. 浏览器打开 `https://app-auth.gudq.com/activate.html?deviceId=TEST001`
2. 输入**错误**兑换码 → 点「立即激活」→ 看是否报错
3. **不改页面**，直接改成**正确**兑换码 → 再点「立即激活」
   - ✅ 期望：按钮可点击、能再次提交、成功返回激活码
   - ❌ 现状：按钮仍是「激活中…」且不可点 ← **P0-16**
4. 成功后 F12 Console：应无 `TypeError`
5. 点「复制激活码」→ 在老内核/手环上确认有反应 ← **P1-15**

**B. 主库切换（15 分钟，本轮重点）**
1. 后台 → 切换主库到 neon → 记录返回的 `from` / `to`
2. **立刻换一个浏览器（或隐私窗口）**再调一次 `dbstatus`，看主库是否一致
3. 到 Vercel → Edge Config 页面，**肉眼看 `auth_db_primary` 这个值是否存在、是否更新**
   - ❌ 若 Edge Config 里根本没有这个 key → **P0-17 已触发，主库切换完全无效**
4. 检查 Vercel 环境变量里有没有 `VERCEL_OIDC_TOKEN` 或 `VERCEL_TOKEN`
   - ❌ 都没有 → `savePrimary` 必然静默失败

**C. 定时任务（5 分钟）**
1. Vercel → Settings → Environment Variables → 确认 `CRON_SECRET` 存在
2. 后台 → 备份「立即执行」→ 看返回是否 success（401 = 未配置）← **P0-15**
3. 同步「立即执行」同上

**D. 手环端（10 分钟）**
1. 手环 9 Pro / 10 Pro 内置浏览器打开 `login_aXs12.html`、`redeem-counts.html` → 看是否白屏/按钮全死 ← **P1-14**

**E. 视觉（5 分钟）**
