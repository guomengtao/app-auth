## 三、缺陷清单

### P1 —— 界面与适配（影响观感/易读性）

#### **UI-1 首页/用户手册/教程 三页整页用衬线字体渲染（全局 font-family 失效）**

- **定位**：`index.html:10`、`user-guide.html:10`、`course-guide.html:10`
- **实测证据**：`getComputedStyle(document.body).fontFamily` →
  - `index.html` → **`Times`** ❌
  - `activate.html` → `-apple-system, system-ui, Segoe UI, PingFang SC...` ✅
- **原因**：逗号被吞
  ```css
  /* 现状（无效） */
  font-family: -apple-system BlinkMacSystemFont 'Segoe UI' 'PingFang SC' 'Microsoft YaHei' sans-serif;
  /* 应为 */
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif;
  ```
  整串被解析成"一个字体族名"→ 找不到 → 回退浏览器默认**衬线**字体。中文渲染成宋体，与 activate.html 的黑体形成强烈反差，整站看起来"两个产品"。
- **影响端型**：全部（桌面/手机/微信/手环）
- **修复**：补回逗号。同一处还有 `index.html:87`、`user-guide.html:94`、`course-guide.html:151` 的 `'SF Mono' 'Fira Code' monospace`（DEMO 链接等宽字体也失效了）

#### **UI-2 后台图标与图表依赖海外 CDN，加载失败且连带打断初始化**

- **定位**：`admin_Dx23.html:7-8`（CDN 引入）、`:4477`、`:7133`（`lucide.createIcons()`）、`:7134-7140`（初始化序列）
- **CDN 实测（当前网络）**：
  | CDN | 用途 | 实测 |
  |-----|------|------|
  | `cdn.jsdelivr.net` | Chart.js 4.4.7 | **15 秒仍未完成 → 超时** ❌ |
  | `unpkg.com` | lucide（全量包 654KB） | 3.8 秒，且 `@latest` 多一次 302 跳转 ⚠️ |
- **实测渲染截图**（CDN 屏蔽场景 = 国内真实情况）：侧边栏 11 个菜单项**图标全部空白**、左上角品牌图标空白、用户头像空白、"订单走势/激活走势"两张图表**整块空白**、四张统计卡只显示 "-"。
- **连带 bug（比图标丢失更严重）**：`lucide.createIcons()` 没有包 try/catch，一旦 lucide 未定义：
  - `:7134` 抛 ReferenceError → **后面的 `setInterval(loadStats, 30000)` 永远不会注册** → 后台统计数字不再每 30 秒自动刷新
  - 同一行后面的 `?tab=xxx` 直达逻辑也执行不到 → **带 tab 参数的后台链接无法直达面板**
- **影响端型**：后台（桌面）
- **修复**：① 把 lucide 和 Chart.js 下载到仓库本地（如 `public/vendor/`），改相对路径引用 —— 顺手把 654KB 全量包换成按需子集；② 短期止血：给两处 `createIcons()` 包 `try{}catch(_){}`，并把 `:7134` 的 `lucide.createIcons()` 挪到 `setInterval(loadStats, 30000)` **之后**，保证监控不被第三方脚本阻断

#### **UI-3 多处文字对比度不达标（WCAG AA 要求 4.5:1，实测最低 1.22:1）**

- **实测数据**（336px 渲染，自动化对比度计算）：

| 页面 | 文案 | 实测对比度 | 说明 |
|------|------|-----------|------|
| `index.html` | "输入兑换码获取激活码"（紫色卡片描述） | **1.22 : 1** | **截图里几乎看不见** —— 用户看不懂这张卡是干嘛的 |
| `ev-timetable.html` | 页脚版本号 | 1.00 : 1 | 完全看不见 |
| `ev-timetable.html` | 导航 FEATURES / GALLERY / BRAND / CHANGELOG | 2.09 : 1 | |
| `user-guide.html` / `course-guide.html` | 页眉 "激活码管理系统 · 用户手册" / 页脚 | 2.32 : 1 | |
| `course-guide.html` | 7 个功能卡片的描述文字 | 2.85 : 1 | |
| `redeem-counts.html` | "本地" / "线上" 标签 | 2.85 : 1 | |
| `activate.html` | "输入兑换码获取激活码" 副标题 | 2.85 : 1 | |

- **说明**：正文要求 4.5:1，大字（≥24px 或 ≥18.66px 粗体）要求 3:1。上表全部不达标。渐变背景上的白字（如"立即激活"按钮）无法用此法测量，**不算缺陷**。
- **影响端型**：全部；户外/强光下手环和手机上更严重
- **修复**：把浅灰文字从 `#a0a0b0` 一档调到 `#6b7280`（对白底 4.8:1）或更深；`index.html` 紫色卡片描述改用 `rgba(255,255,255,0.92)` 而不是半透明紫

### P2 —— 输入与交互

#### **UI-4 空链接：`ev-schedule.html` 页脚"小米手环系列 / 小米手表系列"**

- **定位**：`ev-schedule.html:1081-1082`，`href="#"`，点击跳回页面顶部
- **用户视角**：页脚"支持设备"栏目明明写着两个系列，点了却没反应/跳到顶，像是坏掉了
- **附带**：同文件 `:788` 的 `nav-logo` 也是 `href="#"`，建议改成 `href="/"`
- **修复**：跳转到米坛资源页（7778/7828/7829/7830/7877），或暂时删掉这两条
- ✅ **其余锚点全部有效**（course-guide 目录 7 个锚点逐一核对通过；ev-schedule/ev-timetable 的 `#gallery/#features/#download/#tech/#showcase` 目标都存在）

#### **UI-5 移动端/手环端点击热区普遍过小（实测最小 17px，建议 ≥44px）**

| 页面 | 元素 | 实测尺寸 |
|------|------|---------|
| `course-guide.html` | 目录 7 个锚点链接 | 高 **20px** |
| `user-guide.html` / `login_aXs12.html` | "← 返回首页" | 高 **18-19px** |
| `ev-schedule.html` | 移动端汉堡菜单 `☰` | **21 × 29px** |
| `ev-timetable.html` | 页脚 "peipeijin @ 米坛社区" | 高 **17px** |

- **影响**：手指误触率高；手环 336px 屏上这类密集小链接更难点中
- **修复**：不一定要改视觉尺寸，给这些元素加 `padding: 10px 0`（或伪元素扩大热区）即可

#### **UI-6 字号 <12px（可读性下限）**

| 页面 | 文案 | 实测字号 |
|------|------|---------|
| `activate.html` | "设备ID来源: 本地生成" | **11.5px** |
| `index.html` | "DEMO 测试链接" | **11.5px** |
| `course-guide.html` | 目录栏 6 个分组标题（"核心操作"等） | **11.5px** |

- **修复**：统一提到 12px 以上（手环端建议 13px）

#### **UI-7 "DEMO 测试链接" 暴露在生产首页**

- **定位**：`index.html`（"设备 Aa09 / Bb19 / Xy99 / TeSt" 四个按钮，链到 `/activate.html?deviceId=Xx99`）
- **问题**：真实付费用户打开首页会看到一块"DEMO 测试链接"区域，容易误点，然后拿着一个演示设备 ID 去走激活流程 → 需要再返回重填，体验割裂
- **修复**：加环境开关（如 `?demo=1` 才显示），或直接移到 admin

### P3 —— 代码质量 / 打磨

#### **UI-8 行高过紧**

- `ev-timetable.html` 主标题 "抬腕之间课表尽在掌握" `line-height: 1.12`（中文大标题建议 ≥1.3，否则上下行贴太近）
- `redeem-counts.html` 统计数字 `line-height: 1.0`（数字显示会被裁切下缘）

#### **UI-9 emoji 当作 Icon 使用，与后台的 lucide 线性图标风格不统一**

- `index.html` 用 🛡️ 🔐 📱 📘，`activate.html` 用 🔑
- emoji 是彩色卡通风格，后台是单色线性风格 → **同一产品两套视觉语言**
- 且 emoji 渲染依赖系统字体：**手环老内核 / 部分安卓可能显示为豆腐块或黑白方框**
- **修复**：统一换成 lucide（后台已有），或换成内联 SVG
