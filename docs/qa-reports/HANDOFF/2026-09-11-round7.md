## 三、为什么 #1 必须今天处理（P0-S 定级说明）

按本项目分级口径：**漏洞只要会造成用户无法正常使用 / 数据丢失 / 页面不可用，一律提到 P0，不放 P4「白嫖类」**。

`?cron=1` 绕过后可触达：

- `section=switch-db`（`:1624`）→ **改主库 → 写 A 读 B → 已付款用户显示未激活**
- `section=sync`（`:1675`）→ **用旧数据覆盖新数据**
- `section=run-task`（`:2179`）→ 执行 backup / sync / afdian-pull
- `section=cron-tasks` POST（`:2091`）→ **可把 `vercelPath` 改成任意 URL**（变相 SSRF）
- 以及 quota / dbswitches / dbstatus / 各类 logs 信息泄露

这不是「白嫖」，是**数据丢失 + 全站服务异常**，所以定 P0-S。

**线上实测证据**（本轮 curl，无任何凭据）：

```
GET /api/admin/health?section=__probe_noop__&cron=1   → HTTP 200  {success:true, overall:"ok", ...}
GET /api/admin/health?section=__probe_noop__          → HTTP 401  {success:false, error:"Not authenticated"}
```
