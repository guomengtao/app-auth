## 这是什么？

**EV 课程表同步器**是一个 Astrobox 插件，装在你的 Android 手机上的 Astrobox App 里使用。

它的作用是：**帮你在不同课程表 App 之间互相迁移课程数据**。

比如你之前在「时光课程表」「WakeUp 课程表」「StarLink」里录好了课表，现在想换到 EV 课程表，不用重新手打一遍——用这个插件一键导入就行。

---

## 能做什么？

### 导入课程表

把你手机上别的课程表 App 的数据，一键导入成 EV 课程表格式。

支持的来源 App：

| 来源 | 说明 |
|------|------|
| 时光课程表 (sgschedule) | 最常用的课程表 App |
| WakeUp 课程表 | 简洁好用的课程表 |
| StarLink 课程表 | 星链接课表 |
| CSES 标准格式 | 通用课程表交换格式 |
| EV 课程表 | EV 课程表自己的格式（换设备时用） |

### 导出课程表

把 EV 课程表的数据导出为通用格式，方便分享给同学，或者换到其他 App 时带走数据。

支持导出的格式：
- EV 课程表格式（.json）
- 时光课程表格式（sgschedule）

### 合并课程表

如果你导入的课表和已有的课表有重叠，插件会自动去重——同一天同一时间的同名课程不会重复出现。

## 怎么用？

### 前提条件

1. 一部 **Android 手机**（不支持 iPhone）
2. 手机上已安装 **Astrobox** App
3. 已安装 **EV 课程表同步器**插件

### 第一步：打开插件

在 Astrobox 里找到「EV 课程表同步器」插件，点击打开。

你会看到主界面，有三个入口：

- **从文件导入** —— 选择你之前导出的课程表 JSON 文件
- **从教务系统导入** —— 如果学校支持，可以直接拉取课表
- **导出课程表** —— 把当前课表导出为文件

### 第二步：导入课表

1. 点击「从文件导入」
2. 选择你要导入的课程表 JSON 文件（比如从时光课程表导出的文件）
3. 插件会自动识别格式
4. 确认导入的课程数量
5. 点击「确认导入」

导入成功后，课表数据就转为 EV 课程表格式了。

### 第三步：导出课表（分享给同学）

1. 点击「导出课程表」
2. 选择导出格式（建议选「EV 课程表格式」）
3. 点击「确认导出」
4. 导出完成后，把生成的 JSON 文件发给同学

## 常见问题

**Q：我该怎么拿到其他 App 的课程表文件？**

A：以时光课程表为例：打开时光课程表 → 设置 → 导出/备份 → 导出为文件。然后把文件发给你的手机，在 Astrobox 插件里选择导入。

**Q：导入后课程数据不对怎么办？**

A：不同 App 的数据格式有差异，有些课程信息（如教室、老师姓名）可能丢失。导入后建议核对一遍，手动补全缺失的信息。

**Q：教务系统导入怎么用？**

A：这个功能需要学校的教务系统支持，并且 Astrobox 运行时环境提供网络能力。如果你的学校不在支持列表中，建议先用「从文件导入」的方式。

**Q：iPhone 能用吗？**

A：Astrobox 目前只有 Android 版，iPhone 用户暂时无法使用。你可以让有 Android 手机的同学帮你操作一次，然后分享导出文件给你。
