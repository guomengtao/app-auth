# Tab 切换最小实验插件

> 目的：验证在 AstroBox 插件环境中，**Tab 切换能否正常工作**。
> 不依赖任何业务逻辑（无导入导出、无设备检测、无对话框 overlay），
> 只有两个 Tab 按钮和一行纯文本内容。

---

## 一、实验目标

| 目标 | 预期行为 |
|------|---------|
| 初始状态 | 显示 "dod" |
| 点击 Tab A | 显示 "dod" |
| 点击 Tab B | 显示 "fox" |
| 两个 Tab 按钮 | 并排可见（flex Row），当前高亮 |
| 无 overlay 干扰 | 没有对话框，没有 `z-index` overlay |

如果成功 → 说明 **Tab 切换机制本身没问题**，之前的问题纯粹是 overlay 状态没有在切 Tab 时清理导致的。

## 三、核心代码

### 3.1 `src/lib.rs` — 状态机 + 事件处理

```rust
use std::sync::Mutex;

wit_bindgen::generate!({
    path: "wit",
    world: "psys-world",
    generate_all,
});

use exports::astrobox::psys_plugin::{
    event::{self, EventType},
    lifecycle,
};
use crate::astrobox::psys_host::ui::Event as UiEvent;

mod ui;

/// 页面状态：只有两个 Tab
#[derive(Clone, Debug, PartialEq)]
enum Page {
    TabA,
    TabB,
}

struct PluginState {
    page: Page,
    render_target: String,
}

static STATE: Mutex<Option<PluginState>> = Mutex::new(None);

impl lifecycle::Lifecycle for Lifecycle {
    fn on_load() {
        let _ = STATE.set(PluginState {
            page: Page::TabA,
            render_target: String::new(),
        });
    }
}

impl event::Event for Event {
    async fn on_event(
        &self,
        _event_type: EventType,
        _event_payload: String,
    ) -> String {
        String::new()
    }

    async fn on_ui_render(&self, element_id: String) {
        STATE.lock().unwrap().as_mut().unwrap().render_target = element_id.clone();
        ui::render_main_ui(&element_id);
    }

    async fn on_card_render(&self, _card_id: String) {}

    async fn on_ui_event(
        &self,
        event_id: String,
        event: astrobox::psys_host::ui::Event,
        _event_payload: String,
    ) -> String {
        let needs_render = match event {
            UiEvent::Click => match event_id.as_str() {
                "btn-tab-a" => {
                    let mut state = STATE.lock().unwrap();
                    let state = state.as_mut().unwrap();
                    state.page = Page::TabA;
                    true
                }
                "btn-tab-b" => {
                    let mut state = STATE.lock().unwrap();
                    let state = state.as_mut().unwrap();
                    state.page = Page::TabB;
                    true
                }
                _ => false,
            },
            _ => false,
        };

        if needs_render {
            let target = STATE.lock().unwrap().as_ref().unwrap().render_target.clone();
            if !target.is_empty() {
                ui::render_main_ui(&target);
            }
        }

        String::new()
    }
}
```

### 3.2 `src/ui.rs` — 极简 UI 渲染

```rust
use crate::astrobox::psys_host::{self, ui};
use crate::{Page, STATE};

const BG_ROOT: &str = "#191919";
const BG_CARD: &str = "#242424";
const FG_PRIMARY: &str = "#ffffff";
const FG_MUTED: &str = "#6f6f6f";
const ACCENT_A: &str = "#2196F3";
const ACCENT_B: &str = "#FF9800";

pub fn render_main_ui(element_id: &str) {
    let page = STATE.lock().unwrap().as_ref().unwrap().page.clone();

    let is_a = page == Page::TabA;

    let tab_a = ui::Element::new(ui::ElementType::Button, Some("Tab A"))
        .size(if is_a { 16 } else { 13 })
        .text_color(if is_a { FG_PRIMARY } else { FG_MUTED })
        .bg(if is_a { ACCENT_A } else { BG_CARD })
        .radius(10)
        .padding(10)
        .margin(2)
        .on(ui::Event::Click, "btn-tab-a");

    let tab_b = ui::Element::new(ui::ElementType::Button, Some("Tab B"))
        .size(if is_a { 13 } else { 16 })
        .text_color(if is_a { FG_MUTED } else { FG_PRIMARY })
        .bg(if is_a { BG_CARD } else { ACCENT_B })
        .radius(10)
        .padding(10)
        .margin(2)
        .on(ui::Event::Click, "btn-tab-b");

    let content_text = if is_a { "dod" } else { "fox" };

    let root = ui::Element::new(ui::ElementType::Div, None)
        .padding(14)
        .bg(BG_ROOT)
        // 标题
        .child(
            ui::Element::new(ui::ElementType::Span, Some("Tab 实验"))
                .size(21)
                .text_color(FG_PRIMARY)
                .margin(6),
        )
        // 两个 Tab 按钮 — Flex Row 并排
        .child(
            ui::Element::new(ui::ElementType::Div, None)
                .flex()
                .flex_direction(ui::FlexDirection::Row)
                .padding(6)
                .margin(8)
                .child(tab_a)
                .child(tab_b),
        )
        // 内容区 — 只显示一行纯文本
        .child(
            ui::Element::new(ui::ElementType::Span, Some(content_text))
                .size(48)
                .text_color(FG_PRIMARY)
                .margin(12),
        );

    psys_host::ui::render(element_id, root);
}
```

## 四、与主插件的关键差异

| 维度 | 主插件 (v1.0.27) | 本实验 |
|------|:---:|:---:|
| 页面状态 | `Import / Export / SelectDevice` (3 态) | `TabA / TabB` (2 态) |
| Tab 按钮数 | 2 | 2 |
| 内容复杂度 | JSON 输入框 + 多个按钮 | 一行纯文本 "dod"/"fox" |
| overlay (`show_format_dialog`) | **有** | **无** |
| 设备检测 | 有 | 无 |
| 异步操作 | `fetch_devices().await` | 无 |
| 总代码量 | ~500 行 | ~110 行 |

**如果本实验成功、主插件失败 → 根因 100% 在主插件的 overlay 或异步竞态。**

## 八、`build_abp.sh`

```bash
#!/bin/bash
set -e
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
DIST_DIR="$PROJECT_DIR/dist"

VERSION=$(grep -o '"version"[[:space:]]*:[[:space:]]*"[^"]*"' "$PROJECT_DIR/manifest.json" | head -1 | sed 's/.*"\(.*\)"/\1/')
OUTPUT="$DIST_DIR/TabExperiment-v${VERSION}.abp"

rm -rf "$DIST_DIR"
mkdir -p "$DIST_DIR"

cp "$PROJECT_DIR/manifest.json" "$DIST_DIR/"
cp "$PROJECT_DIR/icon.png" "$DIST_DIR/" 2>/dev/null || true
cp "$PROJECT_DIR/target/wasm32-wasip2/release/tab_experiment.wasm" "$DIST_DIR/tab-experiment.wasm"

echo "dist contents:"
ls -lh "$DIST_DIR/"

cd "$DIST_DIR"
zip -r "$OUTPUT" . -x "*.abp"

echo ""
echo "ABP built: $OUTPUT"
ls -lh "$OUTPUT"
```

## 十一、实验性：ui-v3 Tabs 组件版本

如果 `api_level: 2` 的 flex 方式可行，可进一步实验 ui-v3 原生 Tabs：

```rust
// ui-v3 版本的核心片段（供参考，不一定是本次实验的内容）
use crate::astrobox::psys_host::ui_v3;

let root = ui_v3::element::new(ui_v3::ElementType::Div, None)
    .padding(14)
    .child(
        ui_v3::element::new(ui_v3::ElementType::TabsRoot, None)
            .child(
                ui_v3::element::new(ui_v3::ElementType::TabsList, None)
                    .child(
                        ui_v3::element::new(ui_v3::ElementType::TabsTrigger, Some("Tab A"))
                            .on(ui_v3::Event::Click, "tab-a"),
                    )
                    .child(
                        ui_v3::element::new(ui_v3::ElementType::TabsTrigger, Some("Tab B"))
                            .on(ui_v3::Event::Click, "tab-b"),
                    ),
            )
            .child(
                ui_v3::element::new(ui_v3::ElementType::TabsContent, Some(content_text)),
            ),
    );

ui_v3::render(element_id, root);
```

但这需要 `api_level: 3` 和 `psys-world-v3`，改变接口签名（`on_ui_event_v3` 等），改动范围较大。**建议先用 api_level 2 的 flex 方式完成基本验证，确认 Tab 切换可行后再评估是否要迁移到 ui-v3。**
