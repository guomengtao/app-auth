# 屏幕位置指定功能 设计方案

## 概述

在 Auto Clicker 中增加**屏幕位置指定**功能，用户运行后在屏幕上截取一个或多个位置区域，每个区域以线框悬浮显示，可移动、可调整大小、可独立配置处理逻辑。

## 功能目标

| 需求 | 说明 |
|------|------|
| 截取位置 | 运行后在屏幕上框选一个矩形区域 |
| 线框样式 | 半透明边框 + 编号标签，始终悬浮在所有窗口之上 |
| 移动 | 拖拽线框可移动位置 |
| 调整大小 | 拖拽右下角手柄可缩放 |
| 多个区域 | 支持添加多个线框，每个有独立编号 |
| 取消 | 每个线框可单独删除或隐藏 |
| 线框持久 | 线框一直保持显示，除非手动关闭 |
| 独立处理逻辑 | 每个区域绑定不同的自动操作（点击、OCR、滚动等） |

## 线框外观

```
┌──────────┬──────────────────────────┐
│ #1 全部采纳                          │ ← 编号 + 标签名（拖拽移动）
│                                     │
│                                     │
│           透明区域                    │ ← 线框内透明，不遮挡下方内容
│                                     │
│                                     │
│                               ┌───┐ │
│                               │ ◥◤ │ │ ← 缩放手柄（拖拽调整大小）
│                               └───┘ │
└─────────────────────────────────────┘
```

**线框特性：**
- 边框宽度 2px，颜色可自定义（默认红色 `#FF4444`）
- 左上角显示编号和标签名称，白色文字 + 彩色背景
- 中间区域透明，不遮挡下方窗口内容
- 对角线十字参考线，便于定位
- 始终置顶，不被任何窗口遮挡
- 已编码的实现方案: Tkinter 透明窗口 (`overrideredirect` + `topmost`)

## 数据结构

每个区域存储为 JSON 配置：

```json
{
  "id": "region_1726410000",
  "label": "全部采纳",
  "x": 298,
  "y": 659,
  "width": 120,
  "height": 40,
  "color": "#FF4444",
  "enabled": true,
  "action_type": "click",
  "action_config": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一标识，自动生成 |
| `label` | string | 是 | 显示标签，用户命名 |
| `x`, `y` | int | 是 | 左上角屏幕坐标 |
| `width` | int | 是 | 宽度（最小 30px） |
| `height` | int | 是 | 高度（最小 20px） |
| `color` | string | 是 | 线框颜色，十六进制 |
| `enabled` | bool | 是 | 是否启用（关闭时线框隐藏） |
| `action_type` | string | 是 | 处理逻辑类型 |
| `action_config` | object | 否 | 处理逻辑参数 |

配置文件路径: `~/.auto_clicker_regions.json`

## 处理逻辑类型

每个区域可独立选择处理类型：

| action_type | 名称 | 作用 | 额外参数 |
|-------------|------|------|----------|
| `click` | 定时点击 | 按间隔点击区域中心坐标 | `interval_seconds` |
| `ocr` | 文字识别 | 截图后 OCR 识别区域文字 | `watch_text`, `language` |
| `scroll` | 自动滚动 | 在区域内向下/向上滚动 | `scroll_distance`, `direction` |
| `screenshot` | 定时截图 | 截取区域保存为文件 | `save_path` |
| `none` | 仅标记 | 无操作，纯视觉标注 | 无 |

**默认行为：** 新建区域默认 `action_type = "click"`，点击区域几何中心 `(x + width/2, y + height/2)`。

## 交互方式

### 创建区域

1. 菜单栏 → **"+ New Region"**
2. 弹出命名对话框，输入标签名
3. 区域自动创建在鼠标当前位置，默认大小 120×40
4. 线框立即显示在屏幕上

### 编辑区域（编辑模式）

| 操作 | 方式 |
|------|------|
| 开启编辑模式 | 菜单栏 → **"Edit Mode: ON"** |
| 移动位置 | 拖拽线框的边框或标签区域 |
| 调整大小 | 拖拽右下角蓝色手柄 |
| 关闭编辑模式 | 菜单栏 → **"Edit Mode: OFF"**（线框恢复只读） |

### 管理区域

| 操作 | 方式 |
|------|------|
| 启用/禁用 | 菜单栏 → 点击区域名称切换 `[ON]/[OFF]` |
| 修改处理逻辑 | 菜单栏 → 点击区域名称 → 弹出对话框选择 action 类型 |
| 修改颜色 | CLI 或配置文件手动编辑 `color` 字段 |
| 删除单个 | CLI `--region-clear` 编辑配置文件删除对应条目 |
| 删除全部 | 菜单栏 → "Remove All Regions" |

## 技术实现

### 核心组件

```
RegionManager         ← 总管，管理所有区域生命周期
  ├── RegionOverlay   ← 单个区域的 Tkinter 窗口
  │   ├── 线框绘制（Canvas）
  │   ├── 编号标签
  │   ├── 十字参考线
  │   ├── 缩放手柄
  │   ├── 拖拽事件绑定
  │   └── 缩放事件绑定
  ├── load_regions()  ← 从 JSON 文件恢复配置
  ├── save_regions()  ← 持久化到 JSON 文件
  └── get_click_positions() ← 获取所有 click 类型区域的中心坐标
```

### Tkinter 窗口参数

```python
root.overrideredirect(True)       # 去掉标题栏，纯线框
root.attributes("-topmost", True)  # 始终在最上层
root.attributes("-alpha", 0.85)    # 半透明（边框更柔和）
canvas.config(bg="systemTransparent")  # Mac 透明背景
```

### 编辑模式切换

- **关闭编辑模式**：解绑所有鼠标事件，线框纯显示，点击穿透到下层窗口
- **开启编辑模式**：绑定拖拽和缩放事件，用户可以移动和调整线框

### 点击穿透（显示模式）

在编辑模式关闭时，虽然 Tkinter 的 `overrideredirect` 窗口无法直接设置鼠标穿透，但利用 `-alpha` 只显示边框的特性，边框内的透明区域不会干扰用户操作下方窗口。

## 使用场景举例

| 场景 | 区域配置 | 处理逻辑 |
|------|---------|---------|
| AIoT IDE "全部采纳"按钮 | #1 框住确认按钮 (298, 659, 120×40) | `click`, 间隔 3 秒，dry-run 先测试 |
| VSCode "继续"对话框按钮 | #2 框住底部 (850, 730, 100×35) | `click`, 间隔 3 秒 |
| 监控面板状态变化 | #3 框住状态栏 (100, 200, 300×100) | `ocr`, 检测 "error" 关键词 |
| 长列表自动翻页 | #4 框住列表区域 (200, 300, 400×300) | `scroll`, 每 10 秒向下滚动 |

## CLI 命令

| 命令 | 作用 |
|------|------|
| `--region-new` | 在当前鼠标位置创建新区域（弹出命名框） |
| `--region-list` | 列出所有已配置的区域 |
| `--region-clear` | 清除所有区域 |
| `--cli` | 启动监控循环（含区域点击） |
| `--test-pos` | 测试所有区域位置（dry-run） |

## 与现有功能的关系

```
Auto Clicker v1.2.0
├── 菜单栏 GUI (rumps)          ← 总控入口
├── 按钮检测 (AppleScript)      ← 扫描窗口按钮文字
├── 坐标点击 (Quartz CGEvent)   ← 底层点击引擎
├── 位置记录 (positions.json)   ← 单点坐标（旧功能）
└── 区域管理 (regions.json)     ← 本方案：多区域线框 + 自定义处理逻辑 ★
```
