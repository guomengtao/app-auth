## 一、项目概览

Ev Notifier 是一个 Mac 菜单栏常驻应用，通过 Redis PUB/SUB 实时接收 Vercel 服务端推送的订单、激活、页面访问等事件，并弹出 macOS 原生通知。

```
Vercel Serverless  ──PUBLISH──►  Upstash Redis  ──SUBSCRIBE──►  Ev Notifier (Mac)
                                                                      │
                                                               macOS 通知 + 仪表盘
```

## 五、Redis 免费额度消耗分析

### 5.1 当前架构的消耗模型

Ev Notifier v2.2.5 使用 **PUB/SUB 模式**，客户端通过 Redis 原生 TLS TCP 连接订阅，不走 HTTP REST API。消耗分析如下：

```
                    ┌──────────────┐
   服务端 ──XADD──►  │  Upstash     │  ◄──SUBSCRIBE──  Ev Notifier (Mac)
   服务端 ──INCR──►  │  Redis       │       (原生TCP, 不占RESTAPI配额)
                    └──────────────┘
                         │
   补偿轮询 ──XRANGE───►  (HTTP REST, 按命令计费)
```
