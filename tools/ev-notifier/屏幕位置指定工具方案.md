# 屏幕位置指定工具 方案

## 一、需求概述

制作一个 macOS 小工具，用于在屏幕上创建**可拖拽移动、可调整大小、持久显示的线框区域**。支持多显示器、支持多个区域编号管理、每个区域绑定独立的处理逻辑。

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 画线框 | 运行后在屏幕上拖拽创建矩形线框 |
| R2 | 移动位置 | 线框可拖拽移动到屏幕任意位置 |
| R3 | 调整大小 | 通过右下角手柄拖拽缩放尺寸 |
| R4 | 线框样式 | 彩色边框 + 编号标签，始终悬浮在所有窗口之上 |
| R5 | 添加多个 | 支持同时创建和管理多个线框区域 |
| R6 | 编号标识 | 每个线框有唯一编号和自定义名称 |
| R7 | 取消/删除 | 每个线框可单独删除或禁用 |
| R8 | 持久显示 | 线框始终悬浮，重启后自动恢复 |
| R9 | 不同处理逻辑 | 每个区域可绑定不同操作（点击/OCR/滚动/截图） |
| R10 | 多显示器 | 识别并区分每个显示器，区域绑定到对应屏幕 |
| R11 | 菜单栏显示 | 顶部菜单栏显示图标，底部 Dock 栏不显示图标 |

## 三、多显示器支持方案

### 3.1 获取显示器信息

```python
# 方案 A：使用 PyObjC（最准确）
from AppKit import NSScreen
screens = NSScreen.screens()
for i, screen in enumerate(screens):
    frame = screen.frame
    # frame.origin.x, frame.origin.y, frame.size.width, frame.size.height
    print(f"屏幕 {i}: ({frame.origin.x}, {frame.origin.y}) {frame.size.width}x{frame.size.height}")

# 方案 B：使用 system_profiler（无需额外依赖）
# subprocess.run(["system_profiler", "SPDisplaysDataType"])

# 方案 C：使用 Tkinter 虚拟屏幕
# root.winfo_screenwidth() / root.winfo_screenheight()
# 但只能获取主屏幕 + 虚拟屏幕总大小
```

**推荐方案 A（PyObjC）**，原因：
- 获取每个屏幕的精确坐标范围和尺寸
- 可获取屏幕名称、是否主屏幕、是否内置屏幕
- PyObjC 在 macOS 上默认可用（系统自带 Python 包含）

### 3.2 区域绑定到屏幕

区域配置中增加 `screen_index` 字段：

```json
{
  "id": "region_1726410000",
  "label": "全部采纳",
  "x": 298,
  "y": 659,
  "width": 120,
  "height": 40,
  "screen_index": 1,
  "screen_name": "DELL U2723QE",
  ...
}
```

### 3.3 显示器断开/重连处理

| 场景 | 处理方式 |
|------|----------|
| 显示器断开 | 该屏幕上的区域自动隐藏，其他屏幕区域不变 |
| 显示器重连 | 自动恢复该屏幕上的区域（位置不变） |
| 新显示器接入 | 自动检测，创建区域时可选择目标屏幕 |
| 主显示器切换 | 区域跟随全局坐标，不受主屏切换影响 |

### 3.4 多显示器坐标系

macOS 多显示器使用**全局坐标系**，左下角为原点 (0, 0)。Tkinter 窗口坐标也使用全局坐标，所以：

```
显示器 1（主屏，2560x1440）：frame = (0, 0, 2560, 1440)
显示器 2（副屏，1920x1080）：frame = (2560, 0, 1920, 1080)

全局坐标范围：(0, 0) 到 (4480, 1440)
```

区域坐标 `(x, y)` 是全局坐标，直接对应 Tkinter `geometry(f"{w}x{h}+{x}+{y}")`。

判断区域所属屏幕：
```python
def get_screen_for_region(x, y, width, height):
    cx, cy = x + width // 2, y + height // 2
    for i, screen in enumerate(screens):
        fx, fy = screen.frame.origin.x, screen.frame.origin.y
        fw, fh = screen.frame.size.width, screen.frame.size.height
        if fx <= cx <= fx + fw and fy <= cy <= fy + fh:
            return i, screen
    return -1, None
```

## 四、菜单栏显示 / Dock 栏隐藏方案

### 4.1 技术方案

| 组件 | 方案 |
|------|------|
| Info.plist | `LSUIElement = true`（隐藏 Dock 图标） |
| 启动器 | Swift 原生二进制（最可靠的隐藏方式） |
| 菜单栏 | rumps 库（Python 菜单栏框架） |

### 4.2 构建流程

```
1. Python 脚本：auto_clicker_v1.4.0.py（使用 rumps 菜单栏）
2. Swift 启动器：launcher.swift（桥接 python3 启动脚本）
3. Info.plist：LSUIElement = true
4. 打包：build_app.sh 生成 .app

输出：RegionManager.app（双击启动，仅菜单栏显示）
```

### 4.3 Info.plist 关键配置

```xml
<key>LSUIElement</key>
<true/>
```

### 4.4 Swift 启动器说明

Swift 启动器的作用：
1. 找到 Python 脚本路径（相对于 .app bundle）
2. 找到系统 python3 路径
3. 启动 Python 子进程
4. 因为是原生 macOS 可执行文件，LSUIElement 设置完全生效

## 五、处理逻辑方案

### 5.1 支持的操作类型

| 类型 | 名称 | 描述 | 实现方式 |
|------|------|------|----------|
| `click` | 定时点击 | 按间隔点击区域中心 | `osascript` 模拟鼠标点击 |
| `ocr` | 文字识别 | 截图 + OCR 识别文字 | `Quartz` 截图 + `pytesseract` |
| `scroll` | 自动滚动 | 区域内模拟滚动 | `osascript` 模拟滚轮事件 |
| `screenshot` | 定时截图 | 截取区域保存文件 | `Quartz CGWindowListCreateImage` |
| `none` | 仅标记 | 纯视觉标注 | 无操作 |

### 5.2 每个区域独立配置

```json
{
  "action_type": "click",
  "action_config": {
    "interval_seconds": 3,
    "click_mode": "center",
    "click_offset_x": 0,
    "click_offset_y": 0
  }
}
```

### 5.3 定时任务调度

每个区域在独立线程中运行处理逻辑，不影响主线程 UI：

```
主线程（rumps 菜单栏 + Tkinter 窗口）
    ├── 子线程 #1: 区域 click 循环（每 3 秒）
    ├── 子线程 #2: 区域 click 循环（每 5 秒）
    ├── 子线程 #3: 区域 ocr 循环（每 5 秒）
    └── ...
```

## 九、关键代码示例

### 9.1 多显示器检测

```python
# 使用 PyObjC 检测所有显示器
from AppKit import NSScreen

def get_all_screens():
    screens = NSScreen.screens()
    result = []
    for i, screen in enumerate(screens):
        frame = screen.frame
        is_builtin = getattr(screen, 'isBuiltin', lambda: False)()
        name = "内置显示器" if is_builtin else f"外接显示器 {i}"
        result.append({
            "index": i,
            "name": name,
            "x": int(frame.origin.x),
            "y": int(frame.origin.y),
            "width": int(frame.size.width),
            "height": int(frame.size.height),
            "is_primary": i == 0,
        })
    return result
```

### 9.2 判断区域所属屏幕

```python
def get_region_screen(region, screens):
    cx = region["x"] + region["width"] // 2
    cy = region["y"] + region["height"] // 2
    for s in screens:
        if s["x"] <= cx <= s["x"] + s["width"] and \
           s["y"] <= cy <= s["y"] + s["height"]:
            return s["index"]
    return -1
```

## 十、风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Tkinter 在多显示器高 DPI 下坐标偏移 | 位置不准 | 使用 PyObjC 坐标转换 |
| 全屏应用遮挡 topmost 窗口 | 线框不可见 | 提示用户，全屏应用无法覆盖 |
| 系统睡眠后窗口丢失 | 区域消失 | 监听睡眠通知，自动重建 |
| rumps + Tkinter 多线程冲突 | UI 卡顿 | 主线程跑 UI，子线程跑处理逻辑 |
| PyObjC 在某些 Python 版本不可用 | 屏幕检测失败 | 降级使用 `system_profiler` |
