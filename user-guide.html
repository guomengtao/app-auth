推荐 · 安卓手机快速激活（免扫码、免手输 18 位）

只需在手机 App 里输入 4 位兑换码，激活码自动生成并写入手环：

  1. 下载安卓 App：⬇ 下载 Ev课程表 APK　仅安卓；iOS 请用下方备用方式

装了 App 还同步获得：课表导入导出、上课提醒、桌面小组件。激活中途蓝牙断开也没关系，App 会自动暂存、连上后继续。

FAQ

How to install EV Timetable on my band?
Recommended: Deck Install (open on phone browser, one-click install). If Deck is not suitable, use Astrobox with RPK: Download RPK, see User Guide.
What is Astrobox and where to download?
Astrobox is a third-party app manager for Xiaomi bands/watches, used to install community apps (.rpk format). Download: https://astrobox.online/downloads/, or search "Astrobox" on Ku'an. RPK packages at BandBBS.
Cannot find "EV Timetable" in Astrobox?
Make sure Astrobox is up to date. If still not found, manually download the .rpk file for your model from BandBBS: RPK Download, then use "Local Install" in Astrobox. Or join QQ group: 936886288 for help.
Redeem code says "already used"?
This code has already been redeemed. If this is your first time, double-check the code is correct (4 digits, no spaces). If still getting the error, contact author via Afdian private messages.
Device ID mismatch with band?
The activation code is bound to the Device ID. If the Device ID used during activation differs from the band, the band will fail to decode. Solution: go back to activation page and regenerate with the correct Device ID.
How long is the activation valid?
Depends on your purchased plan (1 month / 3 months / 6 months / 12 months / Lifetime). After activation, the band will remind you 7 days before expiry. Renew and repeat the process.
Got a new band?
New band has a new Device ID. The original redeem code is bound to the old device and cannot be reused. Contact the author for a new redeem code. QQ group: 936886288
Band shows invalid activation code?
1. Check the 18-digit code for entry errors (no extra/missing digits); 2. Confirm Device ID matches the one used during activation; 3. If all looks correct, try regenerating on the activation page; 4. Still stuck? QQ group: 936886288.
How to contact the author?
Join QQ group: 936886288 and contact the author. Or send a private message on Afdian.
