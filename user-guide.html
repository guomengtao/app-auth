用户激活手册

从下载到手环激活，完整 4 步走

1
下载并安装手环 App

在手机应用商店搜索对应 App，下载安装后打开。首次打开会自动生成设备 ID（也叫设备码）。

💡 提示：设备 ID 是手环的唯一标识，用于区分不同设备，请妥善保管。
2
购买并获取兑换码

前往爱发电（或官方渠道）购买对应产品的赞助，完成后系统会自动发送一封邮件，里面包含一个 4 位兑换码。

兑换码示例：ABCD

如果你已在爱发电完成赞助但没收到兑换码邮件，可以：

  • 检查邮件垃圾箱
  • 或在爱发电私信作者手动获取
3
在线兑换，获取激活码

在手机浏览器或电脑上打开激活页面：

前往激活页面

页面会自动填入你的设备 ID（也可以手动输入），然后：

  • 确认设备 ID 与手环 App 上显示的一致
  • 输入 Step 2 收到的 4 位兑换码
  • 点击「立即激活」
⚠️ 注意：兑换成功后，兑换码作废。如果激活码丢了可以重新输入同一个兑换码再生成一次（但兑换码有效期取决于你的赞助时长）。
4
输入激活码到手环

激活页面会显示一个 18 位激活码，把它复制下来：

激活码示例：012345678901234567

打开手环 App → 找到「激活」或「授权」入口 → 粘贴或手动输入这 18 位码 → 确认。

✅
激活成功！手环已解锁完整功能

常见问题

兑换码输入后提示「已使用」怎么办？
说明这个兑换码已经被兑换过了。如果你是首次兑换，请确认兑换码输入正确（4 位，不含空格）。如果确认无误但仍提示已使用，请通过爱发电私信作者核实。
设备 ID 和手环上的不一致会怎样？
激活码是绑定设备 ID 的。如果激活时填的设备 ID 和手环 App 上的不一样，手环会解码失败。解决方法：回到激活页面，用正确的设备 ID 重新生成一次激活码。
激活码有效期是多久？
取决于你购买的产品套餐（1个月 / 3个月 / 6个月 / 12个月 / 永久）。激活成功后，到期前 7 天手环会提醒续期，续期后重新走以上流程即可。
换了新手环怎么办？
新手环有新的设备 ID，需要用同一个兑换码重新在激活页面生成新的激活码即可。兑换码支持重复兑换（在有效期内）。
手环显示激活码无效怎么办？
① 检查 18 位码有没有输入错误（不要多/少字符）；② 确认设备 ID 和激活时填的一致；③ 以上都没问题的话，去激活页面重新生成一次试试。
