用户激活手册

手环 App 内显示 3 个步骤，照着走就行

⌚
安装 EV课程表到手环

首次使用需通过 Astrobox 推送到手环（只需操作一次）：

  1. 手机安装 Astrobox：
    下载 Astrobox
  2. 打开 Astrobox → 搜索「EV课程表」
  3. 点击「下载」，等待推送到手环

支持机型：10 Pro · 9 Pro · 9 · S3/S4（方屏/胶囊/圆屏，Astrobox 自动匹配）

1
购买高级版兑换码

前往爱发电购买

购买后邮箱会收到一个 4 位兑换码：

兑换码示例：ABCD

如果没收到：请在爱发电私信查收。

2
获取激活码

手环打开 Ev课程表 → 设置 → 高级版，滑到第二步会显示设备 ID 和一个二维码。

📱 手机扫码，浏览器会自动打开激活页面。

在页面中输入 Step 1 拿到的 4 位兑换码，点击激活，会生成一段 18 位激活码：

激活码示例：012345678901234567
3
输入激活码到手环

回到手环 App 第 3 步，用数字键盘逐位输入 18 位激活码。

输入完成后点击「验证」。

✅
激活成功！手环升级为高级版
⚠️ 注意：每个兑换码只能激活一次。换新设备需联系作者重新获取。

常见问题

Astrobox 是什么？在哪里下载？
Astrobox 是小米手环/手表的第三方应用管理工具，用于安装社区应用（.rpk 格式）。下载地址：https://astrobox.online/downloads/，也可在酷安搜索「Astrobox」下载。
在 Astrobox 里搜不到「EV课程表」怎么办？
请确认 Astrobox 是最新版本。如果仍搜不到，可以到米坛社区手动下载对应机型的 .rpk 文件，然后在 Astrobox 中通过「本地安装」导入。或加 QQ 群：936886288 获取帮助。
兑换码输入后提示「已使用」怎么办？
说明这个兑换码已经被兑换过了。如果你是首次兑换，请确认兑换码输入正确（4 位，不含空格）。如果确认无误但仍提示已使用，请通过爱发电私信作者核实。
设备 ID 和手环上的不一致会怎样？
激活码是绑定设备 ID 的。如果激活时填的设备 ID 和手环 App 上的不一样，手环会解码失败。解决方法：回到激活页面，用正确的设备 ID 重新生成一次激活码。
激活码有效期是多久？
取决于你购买的产品套餐（1个月 / 3个月 / 6个月 / 12个月 / 永久）。激活成功后，到期前 7 天手环会提醒续期，续期后重新走以上流程即可。
换了新手环怎么办？
新手环有新的设备 ID，原兑换码绑定旧设备，不能在新设备上重新激活。你需要联系作者重新获取兑换码。QQ 群：936886288
手环显示激活码无效怎么办？
① 检查 18 位码有没有输入错误（不要多/少字符）；② 确认设备 ID 和激活时填的一致；③ 以上都没问题的话，去激活页面重新生成一次试试。④ 仍无法解决，QQ 群：936886288 联系作者。

请加 QQ 群：936886288，群内联系作者处理。或在爱发电私信作者。
