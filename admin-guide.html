登录后台
使用 Vercel 账户授权登录
1
访问 登录页，或者直接打开 /admin_Dx23.html
2
点击「Sign in with Vercel」，用你的 Vercel 账户完成授权
3
授权成功后自动跳转后台主页
注意：只有被设为管理员的 Vercel 账户才能登录。非管理员会看到「非管理员账户，无权限访问」。
添加新产品 核心操作 #1
创建一个新的产品/套餐，之后可以为它生成兑换码
1
侧边栏点击 「产品管理」 tab
2
点击右上角 「+ 添加产品」 按钮
3
在弹窗中填写：
  • 产品名称（必填）：显示给用户看的名字，如「Pro 版 12 个月」
  • 产品描述（可选）：详细说明
4
点击 「创建」，系统会自动分配一个两位数字的产品 ID（如 01、02）
💡 系统自动分配 ID，不需要手动填。 第 1 个产品 = 01，第 2 个 = 02，以此类推。最多支持 99 个产品。
编辑已有产品 核心操作 #2
修改产品名称或描述
1
产品管理 tab → 找到要编辑的产品
2
点击产品行右侧的 「编辑」 按钮（或直接点产品卡片上的编辑图标）
3
修改名称或描述 → 点击 「保存」
⚠️ 产品 ID 不能改。ID 是创建时自动分配的两位数字，一旦创建就固定不变。已发放的兑换码和激活记录都绑定这个 ID。
💡 删除产品 = 软删除。删除后产品从列表消失，但已发放的兑换码和激活记录会保留，不会受影响。新兑换码无法再选择这个产品。
生成兑换码
为某个产品批量生成 4 位兑换码，然后发放给用户
1
侧边栏点击 「兑换码管理」 tab → 点击 「+ 生成兑换码」
2
填写三个参数：
  • 所属产品：下拉选择已创建的产品
  • 有效期：1 / 3 / 6 / 12 个月，或 99 = 永久
  • 数量：一次生成多少个兑换码
3
点击 「生成」，系统会返回所有新生成的 4 位兑换码
💡 兑换码格式说明：
参数说明
格式4 位大写字母，如 AB3D
使用次数一次兑换后标记为「已使用」，不能再用
有效期从兑换激活当天开始计算（不是从生成当天）
设备绑定兑换时绑定设备 ID，同一兑换码不能跨设备使用
关键规则说明
这些规则决定了数据怎么存、怎么关联，操作前最好清楚
项目 格式 说明
产品 ID 01 ~ 99 两位数字，系统自动分配，创建后不可修改
兑换码 ABCD 4 位大写字母+数字，随机生成，一次性使用
激活码 012345678901234567 18 位数字，兑换成功时生成，绑定设备 ID
设备 ID Aa09 ~ 4-20 位 手环 App 自动生成，激活时填入
有效期 1~99 单位：月。99 = 永久
⚠️ 不要手动修改 Redis 数据！所有数据操作请通过后台界面完成。直接改 Redis 可能导致索引不同步（如兑换码 set 和 hash 记录不一致）。
