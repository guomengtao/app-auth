多格式课程表一键导入

无论是自家导出、还是从拾光 / WakeUp / 星链 / CSES / 日历(ICS) 等主流课表 App 迁移， Ev课程表 都能识别并导入。下面每种格式都提供了真实示例文件，可直接下载体验。

EV Schedule 自家标准

EV课程表导出的统一格式，是跨端同步的首选。支持课表名、晚课轮转等完整字段。

下载示例 ev.json

拾光课程表 ShiGuang

识别 timeSlots + startSection 结构，课程跨多节时自动拼出起止时间。

下载示例 shiguang.json

WakeUp 课程表

识别 scheduleName + courseList，星期与起止时间直接映射，含单双周类型。

下载示例 wakeup.json

星链课表 StarLink

识别 subjectName + weekRange，按周次区间展开，支持单双周标记。

下载示例 starlink.json

CSES 标准 通用

高校/通用标准格式（cses_version + day_of_week），适合教务系统对接导出。

下载示例 cses.json

ICS / iCalendar 日历

识别 VEVENT + RRULE 每周重复，按 BYDAY 拆分课程；通用日历格式，Outlook/Google 日历均可导出。

下载示例 sample.ics

如何使用

1
打开 EV 同步器
在安卓同步器 App 或网页端，进入「导入课表」。
2
选择来源格式
从列表选择你的课表来源（EV / 拾光 / WakeUp / 星链 / CSES / ICS），或先点「载入示例数据」体验。
3
载入或选择文件
粘贴/选择对应格式的文件，或一键载入我们提供的示例，即时预览解析结果。
4
导入到手环
确认无误后「导入到手环」，课程即刻同步到腕上课程表。
以上六种格式均经 真实解析测试：每种示例文件都能被导入引擎正确识别并解析为课程数据，可放心迁移。
