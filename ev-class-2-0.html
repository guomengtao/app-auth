03

两套真实课表，和一个独立的晚课周期

我们塞了两套真实的学校课表进去——八年级、九年级，不是编的样例。你打开就能看到一门课怎么从早排到晚，晚课又是怎么单独循环的。

6周一轮回
  • 晚课独立模块，不挤进白天课表它自己一套循环周期，和白天互不干扰，不会再出现晚上那节把白天排乱的情况。
  • 周期默认 6 周，自己也能改两周一轮、四周一轮都行，按你学校实际来。
  • 数据八年级 / 九年级，真实学校课表带真实班级、真实节次，方便你照着改，不用从空白开始。
04

激活这件事，这次彻底解决

以前最烦的一步：手环删了、重装了、恢复了，高级版就没了，得找客服人工补一遍。现在不用了。

以前

激活信息跟着安装走。手环一重置、应用一删，记录就没了。用户得截图、找客服、报序列号，等人工重新开一遍——慢，而且每次都得来一遍。

现在

同步器直接读手环的 MAC 和 Node ID，生成一份只属于这块设备的识别记录。重装、删除、重置都不影响；装上同步器，自动就认回来。

读设备标识接上手环，读 MAC 与 Node ID 两个硬件值。
生成唯一记录两个值合成一条识别记录，跟你这块手环绑死。
自动认回以后装同步器就行，不用再输码、不用再找客服。
