🛡️ 删除保护

这是最关键的安全设置 — 防止本地"删除标记"同步时误删线上数据。

🟢 推送前校验删除目标是否存在于服务器
推送删除操作前，先去 Postgres 查询该 ID 是否真的存在。如果服务器上没有这条数据（说明之前 pull 失败或从未同步过），就拒绝删除。这能彻底避免本地孤立的删除标记被推到线上造成数据丢失。强烈建议保持开启。
🟡 删除前二次确认弹窗
任何删除产品/兑换码操作都会弹出确认框，防止误点。
🔄 成功同步后自动清理删除标记
每次 pull/push 成功后，自动清空本地的 deletedProductIds / deletedRedeemCodes。推荐开启，避免删除标记堆积。

使用说明

对外链接格式：https://app-auth.gudq.com/go/<slug>

接入方法：把现有的爱发电购买链接 https://ifdian.net/... 替换为 /go/<slug>，用户点击后会被 302 透明地跳转到真实购买地址。

目标 URL 仅后台可见：前端用户访问 /go/<slug> 时只能看到跳转结果，不会泄漏原始地址。

Slug 命名建议：使用 kebab-case，例如 ev-timetable、miband-tool。

数据保留：配置变更不影响历史统计；删除短链后明细仍保留 30 天。
